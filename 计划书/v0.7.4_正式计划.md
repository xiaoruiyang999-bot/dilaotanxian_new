> 版本线：《v0.7_Demo玩法计划书.md》§六 + §九 v0.7.4 执行卡。

## 一、目标与范围

1. **数据结构**：`SkillData` SO（法力消耗/CD/类型/伤害倍率/AOE 半径/占位色/等级字段+等级数值表）、`SkillBranchData` SO（小技能分支列表）；
2. **执行器**：`SkillExecutor`（玩家组件，运行时挂载）：三槽装配（小技能=分支选中项 / 大招 / 武器技能）、CD 计时、法力校验（TryConsumeMana 已存在）、按类型执行、伤害走 DamageContext/DamageResolver；
3. **四槽接线**：SlotBarUI 三槽显示技能名+CD 秒数；输入 F（Skill 已有）/ Q / R（.inputactions 新增 Ultimate/WeaponSkill 两个 action）；
4. **切武器换技能**：订阅 PlayerWeaponHolder.OnWeaponChanged，武器技能槽整套替换（CD 独立）；
5. **占位内容**：占位技能「旋风斩」（MeleeAoE 圆形范围）跑通四槽链路；战士分支占位 = 屹立不倒/强力一击（均为旋风斩占位效果，v0.7.5 实装真效果），大招占位 = 燃命（大旋风斩），武器技能占位 = 旋风斩（六武器共用）；
6. **分支局外读写**：RunStateCarrier 加小技能分支选择（Set 方法，死亡保留与 LastChosenClass 同规则）；切换入口 UI 不做（计划书标【待补充】）。

**明确不做（本版）**：战士技能真实效果（v0.7.5）、分支切换 UI、技能等级成长消耗（v0.7.6 天赋）、Radial360 CD 扫面（沿用现有文本秒数，记遗留）、技能正式图标/VFX（色块+文字占位）、伤害数字暴击放大表现。

### 2.5 旋风斩（MeleeAoE）执行规格

- 判定：`Physics2D.OverlapCircleAll(玩家位置, aoeRadius, Enemy 层)` → 每个 `IDamageable` 走 `DamageResolver.Deal`；DamageContext 构建仿 WeaponHitbox.cs:133-139：`baseAttack = PlayerStats.Attack`（武器攻击不并入，技能倍率区独立，占位从简）`multiplier = SkillData.GetDamageMultiplier()`，`critRate/critDamage` 取 PlayerStats；跳过自身与 trigger。
- 表现（纯占位）：灰色圆形范围短显（复用 AttackIndicator 圆形模式， detachOnShow=false 跟随玩家，0.2s 后收起）+ DOTween 缩放缓圈（SpawnHealRing 同款模式，**必须 SetLink**）；无伤害数字。
- 蓄力冲突：技能分发在 PlayerController 层、不进 PlayerCombat 状态机，蓄力中允许放技能（占位不做打断，记遗留）。

## 三、结算/输入链路（本版落地后）

| 动作 | 链路 |
|------|------|
| F 小技能 | Skill action → TryCastSlot(0) → CD/法力校验 → 旋风斩 AOE → SlotBarUI 槽 0 起 CD |
| Q 大招 | Ultimate action → TryCastSlot(1) → 同上（大旋风斩） |
| R 武器技能 | WeaponSkill action → TryCastSlot(2) → 同上（旋风斩） |
| 换武器 | OnWeaponChanged → 武器技能槽整套替换（图标/名称/CD 独立清零） |
| 分支读写 | RunStateCarrier.SetSkillBranch(i)（局外）→ SkillExecutor 装配时读（局内锁定，本版无切换 UI） |

## 四、验收清单

> 场景：`v0_7_PrepRoom` → `v0_7_ClassWeapon`；Game 1920×1080 或 Free Aspect。Play 前切回编辑器让新脚本/资产/action 重导入。

1. `dotnet build Assembly-CSharp.csproj`：0 警告 0 错误（**新增 5 个脚本已手工补 csproj `<Compile Include>`**，自检 #12）；
2. **四槽显示**：进游戏右下四槽 = 屹立不倒·占位 / 燃命·占位 / 旋风斩·占位 / 道具栏（原为"—"的三槽已填名）；
3. **施放**：F/Q/R 各放出圆形 AOE，命中怪掉血（暴击按 PlayerStats 判定）、扣法力、槽位起 CD 秒数倒数；CD 中/法力不足再按无效；
4. **切武器**：地牢里换武器 → 武器技能槽名称/CD 重置，F/Q 两槽不受影响；
5. **分支读写**：RunStateCarrier.SetSkillBranch(1) 后重开一局 → 小技能槽变强力一击·占位（局内锁定，局外可改）；
6. **回归**：普攻/蓄力/连发、C 道具栏、E 拾取、换武器入包照旧。
