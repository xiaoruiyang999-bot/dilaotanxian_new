# v2.0.2 PlayableCharacter 职业角色合并

> 完成日期：2026-09-10  
> 最新分支合并：2026-09-14
> 设计真源：《无名之地_完整游戏开发文档_V2》§6、§20、§22、§23

## 本版目标

把旧的“角色外形 + 职业”两次选择合并为一次职业角色选择。运行时不再同时保存 CharacterId/ClassId，而是只保存 PlayableCharacterId，所有配置由 PlayableCharacterDefinition 派生。

## 已完成

- 新增稳定枚举 PlayableCharacterId 与构建安全的 PlayableCharacterCatalog。
- 扩充 PlayableCharacterDefinition：统一身份、颜色、基础属性、兼容武器池、基础武器、技能、怒痕、普攻和动画目录合同。
- 把旧战士数值迁入狼人：HP 130、护甲 70、法力 100、移速 5、攻击 40、暴击 10%、暴伤 1.5、护甲减伤 0.4、护甲损耗 1。
- 把旧战士两把可用武器迁为狼人“基础刺刀（灰盒）”与“备用短刃（灰盒）”；基础刺刀作为选择、死亡复活后的默认武器。
- 旧战士技能资产保持 GUID 原位迁移为 Werewolf 命名，并接入狼人定义；技能内容本版只迁移，不重新平衡。
- RunStateCarrier、PlayerStats、SkillExecutor、武器拾取、宝箱奖励、准备房、地牢入口和死亡复活全部切到职业角色单一真值。
- CharacterSelectUI 变为唯一选择页；旧 ClassSelectUI、ClassData、ClassCatalog、ClassType 与三份旧职业资产在清除引用并通过回归后删除。
- 准备房选择台由三色职业棱晶改为单一狼人棱晶。

## 横向战斗补充（2026-09-14 合并）

- 玩家仅左右攻击确认为最终合同；敌人的近战、远程、冲锋等所有有方向攻击同样在前摇开始时锁定 Left/Right。召唤与自身中心范围技例外。
- AttackData 新增可编辑的横向判定宽度、攻击起点偏移、方向模式和冲锋距离。需要跨 Y 轴的技能通过自身判定宽度实现，不增加上下攻击方向。
- 敌人攻击距离判断、预警、近战 Hitbox、弹体最大边界与冲锋走廊消费同一份几何配置；冲锋预警纵深覆盖 AttackRange + ChargeDistance。
- 敌人移动、追击和攻击时根节点保持世界旋转 0°；仅通过 SpriteRenderer.flipX 或子级武器表现左右翻转。
- 巡逻、追击、后撤和横移时，未锁定的武器 Pivot 跟随实际水平移动方向；纯纵向移动保持最后水平朝向，攻击期间仍由 Windup 锁定方向优先。
- Space 配合 W/A/S/D 单按或组合输入实现八向 Dash。X 轴位移长、Y 轴位移短，斜向同时按两轴距离并乘独立缩放，避免对角位移过长。
- 狼人 Dash 参数已移入 PlayableCharacterDefinition：X/Y 距离、斜向缩放、持续时间、冷却与收招无敌延长均可在角色资产中调整。
- 补充内容已在保留当前分支存档、Boss P3、敌人词缀、流血/破甲等后续改动的前提下重新合并，没有回退这些系统。

## 关键运行合同

1. RunStateCarrier 只持有 ChosenPlayableCharacterId，不缓存第二份职业或外形身份。
2. 武器兼容性只由 PlayableCharacterDefinition.AvailableWeapons 判断，WeaponData 不再保存 requiredClass。
3. 选择职业角色是一个事务：写入 ID → 应用属性 → 应用外形/能力 → 装备基础武器 → 刷新展台。
4. 死亡保留职业角色，并恢复该定义的基础武器。
5. 当前 Catalog 只发布狼人；法师、弓箭手不得用旧 ClassData 临时接回。
