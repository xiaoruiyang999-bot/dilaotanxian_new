# 《无名之地》Roguelite 长期路线图

> 基线：V2
>
> 更新：2026-09-10
>
> 完整范围：`无名之地_完整游戏开发文档_V2.md`

## 当前目标

先验证“狼人刺刀/狼爪差异化战斗 + 俯视二维走位 + 横向单向房间推进 + DAG 风险选择 + 局内构筑”是否成立，再扩展法师、弓箭手和完整世界。

## 里程碑

### M0：V2 设计与迁移基线

- 合并故事、GDD、技术落地与开发顺序。
- 定案三职业角色、狼人刺刀/狼爪、怒痕大招充能、一体化 Sprite 与 Animator。
- 归档永久百分比技能树及明确无引用旧代码。
- 状态：完成；操作、怒痕、HUD 与星蓝币测试基线已通过用户审查。

### M1：MVP

- v2.0.1 仅左右攻击 + 怒痕时间/伤害充能 + Q 兽化 + 空格/F/Q 输入 + 技能读秒 HUD。
- 当前进度：v2.0.1 与 v2.0.2 代码、资产迁移和自动验证已完成；左右攻击手感与怒痕数值仍需人工调优。
- v2.0.2 PlayableCharacter 合并，战士数据迁为狼人。状态：完成；运行身份、选择、装配、武器兼容和技能入口已统一。
- v2.0.3 狼人刺刀/狼爪 Animator 与 AttackDefinition。
- v2.0.4 3～5 个横向房间 + Camera Bounds。
- v2.0.5 5～7 列小 DAG + 基础奖励闭环。
- 退出条件：10～15 分钟可玩，Y 轴有价值，横向特色与两种形态均成立。

### M2：Vertical Slice

- v2.0.6 3～5 把刺刀、12～18 个强化、星蓝币双钱包和商店。
- v2.0.7 荒废边境、守灯厅、4 种敌人、1～2 精英和叙事碎片。
- v2.0.8 格兰 Boss、10～12 列 DAG、8～12 房间、完整结算与节点存档。
- 退出条件：20～30 分钟完整 Run，至少三种狼人 Build，路线决策有实际代价。

### M3：正式版

- 法师、弓箭手完整实装。
- 旧王国遗迹、月蚀监牢、封印区、钟声之井。
- 完整武器/遗物/事件/敌人/Boss/多周目叙事。
- 内容解锁、难度规则、手柄与辅助设置。

## 冻结规则

- M1 完成前不做第二可玩职业、第二区域和正式资源量产。
- M2 完成前不做联机、锻造、无限模式、每日挑战或大型永久天赋树。
- 任一阶段退出条件未通过，优先修核心体验，不用堆内容掩盖问题。
- 玩法范围只在 V2 主开发文档维护；本文件只保留里程碑摘要。
