# v0.5.2 正式计划：随机内容生成

## 版本信息
- **版本号**：v0.5.2（含原 v0.5.2.1「可破坏障碍物双方可摧毁」——2026-07-22 用户决策并入，v0.5.2.1 版本号取消）
- **版本名称**：随机内容生成（敌人 / 障碍物 / 装饰 全部由配置表驱动）
- **前置版本**：v0.5.1（房间流程系统，人工验收通过）
- **状态**：✅ 已完成（2026-07-22 人工验收通过，实施记录见 `v0.5.2操作.md`）
- **依据**：《v0.5 Dungeon 系统开发计划书》五-C 节 + 《美术策略变更说明》v1.2（可破坏障碍物方案）
- **目标**：每个战斗房的敌人、障碍物、装饰由 SpawnTable 配置随机生成；改内容只改 SO 资产，不改代码；同 seed 下地图与内容完全一致。
- **约束**：
  1. 不碰 Player/Enemy/Combat/Weapon/UI 任何现有脚本；
  2. 敌人内容挂在 contentRoot 下，复用 v0.5.1 的休眠与清房判定（`Room.RegisterEnemy` 入口不变）；
  3. 一切随机走显式 `System.Random`（房间子 seed 派生），禁止 `UnityEngine.Random`；
  4. 美术为程序员美术占位：白图染色色块，可破坏/不可破坏视觉可区分。

## 一、现状分析（v0.5.1 完成度）

### 1.1 可复用资产（本版本不动的部分）

| 资产 | 复用方式 |
|------|----------|
| `Room` 完整状态机 | `RegisterEnemy(EnemyHealth)` 即接管网眠与清房计数，**Spawner 直接复用，零改动入口** |
| `Door` / `RoomTrigger` / contentRoot | 结构不变；内容生成在 Door 建完之后执行（位置规则要读门洞中心） |
| `IDamageable` / `WeaponHitbox` | 可破坏障碍物实现 `IDamageable` 即接入现有武器判定链，**零新判定代码** |
| `Enemy.prefab` | 本阶段唯一敌人种（框架先行，新敌人后续版本加表即可） |
| `WhiteSquare.asset` 白图 | 障碍物/装饰占位的染色底图 |
| 受击闪白 / 死亡销毁表现经验 | `DestructibleObstacle` 沿用「闪白 0.15s + 颜色变化 + 销毁」的表现层工具箱 |

### 1.2 关键工程事实（实施前必须知道）

| 事实 | 影响 |
|------|------|
| Player 在 layer 0 (Default)，Enemy 在 layer 6 (Enemy)，**layer 3~5、7+ 均空闲** | 新建 `Obstacle` 层用 **layer 7**（紧跟 Enemy，跳过历史空位 3） |
| `PlayerAttackData.asset` targetLayer `m_Bits: 64`（仅 Enemy） | 改为 **192**（Enemy 64 + Obstacle 128）；`EnemyMeleeAttackData.asset` 改为 **129**（Default + Obstacle）——**双方武器均可摧毁可破坏障碍物**（用户决策，原「仅玩家可破坏」规则作废） |
| 物理碰撞矩阵 2D 全开（v0.5.1 已核查） | 新层默认与所有层碰撞 → 障碍物自动挡玩家/敌人移动，**矩阵零改动** |
| `WeaponHitbox.Tick` 跳过 `isTrigger` 碰撞体、跳过 `transform.root` 相同者 | 不可破坏障碍物（无 `IDamageable`）被武器扫到也什么都不会发生，天然安全 |
| 房间休眠制是「逐敌人禁用 AI/Combat + 刚体冻结」（v0.5.1 偏差①） | `Room.RegisterEnemy` 内已含休眠调用，Spawner 生成即登记即休眠，**不需要 Spawner 管休眠** |
| `Room.doors` 是 private，位置规则 2（距门 ≥2.5 格）需要门洞中心 | 本版本给 Room 加 1 行只读访问器 `Doors`（唯一一处 Room 改动） |
| 敌人根物体有 radius=5 的 trigger 探测圈；RoomTrigger 也是 trigger | 位置合法性检测用 `useTriggers=false` 的 `OverlapCircle`，自动跳过两类 trigger |
| Walls 的 CompositeCollider2D 在 Default 层 | 位置检测的 LayerMask = Default + Enemy + Obstacle，即可同时防「刷进墙 / 刷进敌人 / 刷进障碍物」 |
| DungeonManager 有 4 个调试摆敌字段（v0.5.1 脚手架） | 本版本**移除**，由 EnemySpawner 正式接管 |

### 1.3 随机流设计

```
主 seed（DungeonManager.ActiveSeed）
  └─► 房间子 seed = ActiveSeed * 7919 + roomId（int 溢出无碍，确定性即可）
        └─► new System.Random(roomSeed) → 该房间全部内容随机（种类/数量/位置）
```

`DungeonBuilder.Build` 签名加第三参 `int layoutSeed`，由 Manager 传 `ActiveSeed`。同 seed → 同布局（已有）+ 同内容（本版本）。

## 二、目标架构

```
DungeonManager.Generate()
  → DungeonGenerator.Generate(config, ActiveSeed)        （不变）
  → DungeonBuilder.Build(layout, config, ActiveSeed)     （+seed 参数）
       ├─ 画房间 / 开门洞 / 建 Room / 建 Door             （不变）
       └─ ★新增：对每个战斗类房间（ClearCondition == AllEnemiesDead）
            roomSeed = seed*7919 + roomId
            EnemySpawner.Spawn(room, profile.enemyTable, rng)        → RegisterEnemy（休眠+清房计数）
            ObstacleSpawner.Spawn(room, profile.obstacleTable, rng)  → 不登记（非清房条件）
            DecorationSpawner.Spawn(room, profile.decorationTable, rng)
```

- 三个 Spawner 均为**静态类**，共用位置合法性工具 `SpawnPositionHelper`；
- 掉落物（打碎掉宝）不在本阶段：`ObstacleHealth.OnDestroyed` 事件即挂点（v0.5.3 宝箱/掉落落地后再接）；
- Start 房不生成任何内容（安全房）；Boss 房本阶段按战斗房处理（生成普通敌人，Boss 占位属 v0.5.3）。

### 生成位置合法性规则（三个 Spawner 共用，`SpawnPositionHelper.TryFind`）

1. 位置在房间内部，距墙 ≥1 格（Bounds 四边内缩 1）；
2. 距所有门洞中心 ≥2.5 格（防堵门，兼任「别刷在玩家脸上」）；
3. `Physics2D.OverlapCircle(r=0.4, useTriggers=false)` 无碰撞体（防重叠、防刷进墙）；
4. 每个位置最多重试 20 次，失败放弃该个（不卡死）。

### 3.1 `Assets/Scripts/v0_5/Content/SpawnTable.cs`

```csharp
using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// 生成权重表（计划书五-C）：一类内容（敌人/障碍物/装饰）的候选 prefab + 权重 + 每房数量区间。
/// 纯数据 + 抽取逻辑（不碰场景）；改内容只改本资产，不改代码。
/// </summary>
[CreateAssetMenu(menuName = "Dungeon/SpawnTable")]
public class SpawnTable : ScriptableObject
{
    [System.Serializable]
    public class Entry
    {
        public GameObject prefab;
        public int weight = 1;
        [Tooltip("仅障碍物表使用：可被玩家武器破坏")]
        public bool destructible;
        [Tooltip("仅障碍物表使用：可破坏时的血量（≈需要砍的刀数）")]
        public int hp = 3;
    }

    public List<Entry> entries = new List<Entry>();
    public int countMin = 2, countMax = 4;   // 每个房间生成数量区间

    /// <summary>按数量区间 roll 本房生成个数。</summary>
    public int RollCount(System.Random rng)
    {
        if (countMax < countMin) countMax = countMin;
        return rng.Next(countMin, countMax + 1);
    }

    /// <summary>按权重抽一个条目；表空或权重全 0 返回 null。</summary>
    public Entry PickEntry(System.Random rng)
    {
        int total = 0;
        foreach (Entry e in entries) if (e != null && e.prefab != null) total += Mathf.Max(0, e.weight);
        if (total <= 0) return null;

        int roll = rng.Next(total);
        foreach (Entry e in entries)
        {
            if (e == null || e.prefab == null) continue;
            roll -= Mathf.Max(0, e.weight);
            if (roll < 0) return e;
        }
        return null;
    }
}
```

### 3.3 `Assets/Scripts/v0_5/Content/SpawnPositionHelper.cs`

```csharp
using UnityEngine;

/// <summary>
/// 生成位置合法性工具（三个 Spawner 共用，计划书五-C 规则 1~4）：
/// ① 距墙 ≥1 格；② 距门洞中心 ≥2.5 格（防堵门 + 别刷玩家脸上）；
/// ③ OverlapCircle(r=0.4) 无实体碰撞（useTriggers=false，自动跳过 RoomTrigger 与敌人探测圈）；
/// ④ 最多重试 20 次，失败放弃该个。
/// </summary>
public static class SpawnPositionHelper
{
    private const float WallMargin = 1f;
    private const float DoorMargin = 2.5f;
    private const float OverlapRadius = 0.4f;
    private const int MaxAttempts = 20;

    // Default(墙/门/装饰) + Enemy + Obstacle：墙、敌人、障碍物都算占位。
    // 注意：依赖 Obstacle 层已存在（任务1 先行创建），缺失时 GetMask 报错并返回 0。
    private static int SolidMask => LayerMask.GetMask("Default", "Enemy", "Obstacle");

    /// <summary>在房间内尝试找一个合法生成点；失败返回 false。</summary>
    public static bool TryFind(Room room, System.Random rng, out Vector3 pos)
    {
        Rect b = room.Bounds;
        for (int attempt = 0; attempt < MaxAttempts; attempt++)
        {
            float x = Mathf.Lerp(b.xMin + WallMargin, b.xMax - WallMargin, (float)rng.NextDouble());
            float y = Mathf.Lerp(b.yMin + WallMargin, b.yMax - WallMargin, (float)rng.NextDouble());
            pos = new Vector3(x, y, 0f);

            if (!FarFromDoors(room, pos)) continue;

            // 静态缓冲 + useTriggers=false：跳过一切 trigger（RoomTrigger / 敌人探测圈）
            int hits = Physics2D.OverlapCircle(pos, OverlapRadius,
                new ContactFilter2D { layerMask = SolidMask, useLayerMask = true, useTriggers = false },
                new Collider2D[4]);
            if (hits > 0) continue;

            return true;
        }
        pos = default;
        return false;
    }

    private static bool FarFromDoors(Room room, Vector3 pos)
    {
        foreach (Door d in room.Doors)
        {
            if (d == null) continue;
            if (Vector2.Distance(pos, d.transform.position) < DoorMargin) return false;
        }
        return true;
    }
}
```

> 说明：`OverlapCircle` 重载使用 Unity 6 的 `ContactFilter2D + Collider2D[]` 形式（与 `WeaponHitbox.Tick` 同一 API 风格）。`new Collider2D[4]` 每房间每生成点一次小分配，非每帧路径，可接受；若洁癖可提为静态缓冲。

### 3.4 `Assets/Scripts/v0_5/Content/EnemySpawner.cs`

```csharp
using UnityEngine;

/// <summary>
/// 敌人生成器（静态）：按权重表在房间内随机放敌人，实例化到 contentRoot 下并 RegisterEnemy。
/// RegisterEnemy 即接管休眠（可见但不动）与清房计数——本类不管休眠、不认识 Room 状态机。
/// </summary>
public static class EnemySpawner
{
    public static void Spawn(Room room, SpawnTable table, System.Random rng)
    {
        if (room == null || table == null) return;

        int count = table.RollCount(rng);
        for (int i = 0; i < count; i++)
        {
            SpawnTable.Entry e = table.PickEntry(rng);
            if (e == null) continue;
            if (!SpawnPositionHelper.TryFind(room, rng, out Vector3 pos)) continue;

            GameObject go = Object.Instantiate(e.prefab, pos, Quaternion.identity, room.ContentRoot);
            go.name = $"{e.prefab.name}_{room.Id}_{i}";
            room.RegisterEnemy(go.GetComponent<EnemyHealth>());
        }
    }
}
```

using UnityEngine;

/// <summary>
/// 障碍物生成器（静态）：放障碍物（色块 + BoxCollider2D，挡移动）。
/// 条目 destructible=true 时按条目 hp 初始化 ObstacleHealth（prefab 上已有则复用，没有则补挂）。

    {

        int count = table.RollCount(rng);
        for (int i = 0; i < count; i++)
        {
            SpawnTable.Entry e = table.PickEntry(rng);
            if (e == null) continue;
            if (!SpawnPositionHelper.TryFind(room, rng, out Vector3 pos)) continue;

            GameObject go = Object.Instantiate(e.prefab, pos, Quaternion.identity, room.ContentRoot);
            go.name = $"{e.prefab.name}_{room.Id}_{i}";

            if (e.destructible)
            {
                ObstacleHealth hp = go.GetComponent<ObstacleHealth>();
                if (hp == null) hp = go.AddComponent<ObstacleHealth>();
                hp.Init(e.hp);
            }
        }
    }
}

### 3.7 `Assets/Scripts/now_use/ObstacleHealth.cs`（非地牢专属，放 now_use）

```csharp
using UnityEngine;

/// <summary>
/// 可破坏障碍物生命（v0.5.2）。实现 IDamageable，直接接入现有 WeaponHitbox 判定链（零新判定代码）。
/// HP 语义 = 需要砍的刀数：每次命中固定扣 1，不看伤害数值（SpawnTable 条目 hp ≈ 刀数）。
/// 只持有数据与事件，不做任何表现——表现由 DestructibleObstacle 监听事件实现。
/// OnDestroyed 是掉落物系统的挂点（v0.5.3+ 接入）。
/// </summary>
public class ObstacleHealth : MonoBehaviour, IDamageable
{
    [SerializeField] private int maxHp = 3;

    public int CurrentHp { get; private set; }
    public int MaxHp => maxHp;
    public bool IsDestroyed { get; private set; }

    public System.Action<int, int> OnHpChanged;  // (current, max)
    public System.Action OnTakeDamage;           // 受击（闪白表现监听）
    public System.Action OnDestroyed;            // 破坏（销毁表现 / 未来掉落挂点）

    private void Awake()
    {
        CurrentHp = maxHp;
    }

    /// <summary>SpawnTable 条目注入血量（≈刀数）。生成时由 ObstacleSpawner 调用。</summary>
    public void Init(int hp)
    {
        maxHp = Mathf.Max(1, hp);
        CurrentHp = maxHp;
        IsDestroyed = false;
    }

    /// <summary>实现 IDamageable。每次命中固定 -1（刀数语义）。</summary>
    public void TakeDamage(float damage)
    {
        if (IsDestroyed) return;

        CurrentHp = Mathf.Max(CurrentHp - 1, 0);
        OnHpChanged?.Invoke(CurrentHp, maxHp);
        OnTakeDamage?.Invoke();

        if (CurrentHp <= 0)
        {
            IsDestroyed = true;
            OnDestroyed?.Invoke();
        }
    }
}
```

### 3.8 `Assets/Scripts/now_use/DestructibleObstacle.cs`（非地牢专属，放 now_use）

```csharp
using UnityEngine;

/// <summary>
/// 可破坏障碍物表现（v0.5.2，程序员美术）：
/// 受击闪白 0.15s（沿用 EnemyController 经验）；随血量颜色变深（裂纹占位）；
/// 破坏时销毁 GameObject（销毁后可通行——碰撞体随之消失）。
/// 与 ObstacleHealth 职责分离：本类不含任何生命数据。
/// </summary>
[RequireComponent(typeof(ObstacleHealth))]
public class DestructibleObstacle : MonoBehaviour
{
    [SerializeField] private SpriteRenderer visual;
    [SerializeField] private float flashTime = 0.15f;
    [Tooltip("血量见底时的最深亮度倍率（1 = 不变深，模拟裂纹用 0.4~0.5）")]
    [SerializeField, Range(0f, 1f)] private float minBrightness = 0.45f;

    private ObstacleHealth health;
    private Color baseColor;
    private Coroutine flashRoutine;

    private void Awake()
    {
        health = GetComponent<ObstacleHealth>();
        if (visual == null) visual = GetComponent<SpriteRenderer>();
        if (visual != null) baseColor = visual.color;

        health.OnTakeDamage += HandleTakeDamage;
        health.OnDestroyed += HandleDestroyed;
    }

    private void OnDestroy()
    {
        if (health != null)
        {
            health.OnTakeDamage -= HandleTakeDamage;
            health.OnDestroyed -= HandleDestroyed;
        }
    }

    private void HandleTakeDamage()
    {
        if (visual == null) return;
        if (flashRoutine != null) StopCoroutine(flashRoutine);
        flashRoutine = StartCoroutine(Flash());
    }

    private void HandleDestroyed()
    {
        Destroy(gameObject);
    }

    private System.Collections.IEnumerator Flash()
    {
        visual.color = Color.white;
        yield return new WaitForSeconds(flashTime);
        visual.color = ShadedColor();
        flashRoutine = null;
    }

    /// <summary>按剩余血量比例把基础色压暗（满血 = 原色，见底 = minBrightness 倍）。</summary>
    private Color ShadedColor()
    {
        float t = health.MaxHp > 0 ? (float)health.CurrentHp / health.MaxHp : 0f;
        float k = Mathf.Lerp(minBrightness, 1f, t);
        return new Color(baseColor.r * k, baseColor.g * k, baseColor.b * k, baseColor.a);
    }
}
```

2. `Build` 签名加 seed 参数，并在建完 Door 后生成内容：

```csharp
/// <summary>按布局重建整层地牢，返回起始房中心（世界坐标）。
/// layoutSeed 用于派生每个房间的内容子 seed（同 seed 下地图与内容完全一致）。</summary>
public Vector3 Build(DungeonLayout layout, DungeonConfig config, int layoutSeed)
{
    roomW = config.roomWidth;
    roomH = config.roomHeight;
    doorW = config.doorWidth;

    ClearAll();
    foreach (RoomNode node in layout.rooms) PaintRoom(node);

    var doorRects = new Dictionary<RoomConnection, Rect>();
    foreach (RoomConnection conn in layout.connections)
    {
        Rect? r = CarveDoor(conn);
        if (r.HasValue) doorRects[conn] = r.Value;
    }
    foreach (RoomNode node in layout.rooms) CreateRoomObject(node);
    foreach (KeyValuePair<RoomConnection, Rect> kv in doorRects) CreateDoor(kv.Key, kv.Value);

    // v0.5.2：内容生成放在最后——位置规则要读门洞中心（门已建）、敌人登记要 Room 已 Init。
    foreach (RoomNode node in layout.rooms) SpawnContent(node, layoutSeed);

    return GetRoomCenterWorld(layout.startRoom);
}

/// <summary>按默认 Profile 为战斗类房间生成敌人/障碍物/装饰（子 seed 派生：seed*7919 + roomId）。</summary>
private void SpawnContent(RoomNode node, int layoutSeed)
{
    if (defaultContentProfile == null) return;
    if (!rooms.TryGetValue(node.id, out Room room)) return;
    if (room.ClearCondition != RoomClearCondition.AllEnemiesDead) return;  // Start 等无战斗房不生成

    var rng = new System.Random(layoutSeed * 7919 + node.id);
    EnemySpawner.Spawn(room, defaultContentProfile.enemyTable, rng);
    ObstacleSpawner.Spawn(room, defaultContentProfile.obstacleTable, rng);
    DecorationSpawner.Spawn(room, defaultContentProfile.decorationTable, rng);
}
```

> 预埋：v0.5.3 只把 `defaultContentProfile` 换成「按 room.Type 从 RoomTypeConfig 取 Profile」，`SpawnContent` 结构不变。

## 七、验收清单

- [ ] 每个战斗房生成 2~4 个敌人（配置区间），数量与位置随 seed 变化
- [ ] 同 seed 重进 → 敌人/障碍物/装饰的种类、数量、位置完全一致（Inspector 填固定 seed 复验两次）
- [ ] 敌人不刷在门洞 2.5 格内、不刷进墙、不与障碍物互相重叠
- [ ] 障碍物挡住玩家移动；装饰无碰撞、渲染在角色脚下（污渍贴地）
- [ ] 可破坏障碍物（浅棕）能被玩家武器击毁：受击闪白 → 随血量颜色变深 → 血尽销毁 → 销毁后可通行
- [ ] 不可破坏障碍物（灰石）被武器扫到无任何反应（无 IDamageable，Hitbox 天然跳过）
- [ ] 敌人和玩家武器均可摧毁可破坏障碍物（双方 targetLayer 均含 Obstacle）
- [ ] 可破坏障碍物不计入清房条件：房内障碍物原样、敌人全灭即开门
- [ ] v0.5.1 流程无回归：未进房敌人休眠（可见不动）、进房关门激活、全灭开门、门开关联动正确
- [ ] 改 SpawnTable 资产（数量/权重/hp）即改变生成结果，全程不改代码（数据驱动验收）
- [ ] 「Validate 1000 Seeds」回归不受影响（生成逻辑未动）
- [ ] Console 无 Error / 无 Warning；Player.prefab / Enemy.prefab 无引用变更

| 风险 | 影响 | 应对 |

## 十、附录：三类可破坏方块——框架设计储备（后续 v0.5 子版本落地，v0.5.2 不实施）

> 用户定义的三类（2026-07-22）：①**特殊方块**——击破后对周围产生特殊效果（炸药箱、毒药箱）；②**物资方块**——击破掉落材料/金币；③**普通装饰方块**——击破即消失（= 现有 Obstacle_Destructible，已落地）。三类均双方武器可摧毁（v0.5.2 已满足判定链前提）。

### 10.1 框架：DestructionEffect 破坏效果 SO 挂点

```
武器命中（玩家或敌人，targetLayer 均已含 Obstacle ✅ v0.5.2 已落地）
  → WeaponHitbox（现有）→ ObstacleHealth.TakeDamage → HP 归零 → OnDestroyed
       → DestructibleObstacle：effect?.Execute(position)  ← 预留挂点（+4 行）
       │     ├─ 普通箱：effect 为空 → 碎裂即消失（现状，已落地）
       │     ├─ 物资箱：DropEffect → 按权重表（复用 SpawnTable）掉 金币占位/治疗球
       │     ├─ 炸药箱：ExplosionEffect → 半径内 IDamageable 全体结算（命中箱子 → 连锁引爆）
       │     └─ 毒药箱：PoisonEffect → 生成 DamageZone（持续伤害区域，到时自毁）
       → 销毁 GameObject
```

- **效果即资产**：新箱型 = prefab 变体（换色）+ 配一份 Effect SO + SpawnTable 加条目，零框架代码；
- **连锁反应是涌现行为**：爆炸走 `IDamageable`，命中其他箱子 → 其 `OnDestroyed` → 各自效果触发，无需特判；
- **Interactable 提前**：v0.5.3 计划的 walk-over 交互基类提前到物资箱落地时实现，v0.5.3 宝箱/祭坛直接复用；
- **ObstacleHealth 伤害语义**：落地爆炸时需把 `TakeDamage` 的「固定 -1」改为 `-max(1, round(damage))`（武器仍是刀数语义，爆炸大额伤害可一次摧毁 → 连锁前提）。

### 10.2 预留脚本设计（落地时按此实现）

| 脚本 | 位置 | 职责 |
|------|------|------|
| `DestructionEffect`（抽象 SO） | `now_use/` | `Execute(Vector3 position)`；普通箱不挂即无效果 |
