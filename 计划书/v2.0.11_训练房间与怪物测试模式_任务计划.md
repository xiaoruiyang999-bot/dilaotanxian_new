>

> 设计真源：本文档为独立工具批次，不改变任何正式玩法数值或流程。
>
> 目标：提供一个专用训练场景，让开发者/策划能直接刷出任意怪物并测试其数值表现，无需进入普通地牢流程。

---

## 0. 核心痛点

当前测试一只怪物数值需要：
1. 进入准备房 → 选择职业角色 → 选择武器
2. 走入传送门进入地牢
3. 沿横向长廊走到某个战斗房间
4. 等待随机生成出想要测试的怪物类型（不可控）
5. 开打并观察数值

Boss 测试更麻烦——需要走到最右端的仪式厅。且刷怪完全随机，想专门测 Summoner 可能一层只遇到一只。

---

## 1. 产品方案

### 1.1 一个独立场景 + 一组快捷键 + 一个统计面板

| 载体 | 内容 |
|---|---|
| `v0_7_TrainingRoom` 场景 | 程序化大平地，玩家出生即战斗就绪 |
| 快捷键（无需点 UI） | 数字键刷怪 / 功能键控制 |
| 实时统计面板（F6 开关） | DPS / 击杀用时 / 存活怪物 HP |

不修改任何正式玩法代码，不进入 Build Settings 正式流（开发者手动打开该场景 Play 即可）。

### 1.2 不做什么

- 不做怪物编辑器（调数值仍去 SO/Prefab）
- 不做自动化数值回归（那是 EditMode 测试的事）
- 不做正式美术（程序色块即可）
- 不修改现有地牢/准备房/战斗代码
- 不加入 Build Settings 正式流（纯开发工具，不上玩家端）

## 2. 场景设计

### 2.1 房间构建

由 `TrainingRoomManager`（MonoBehaviour）在 `Start()` 程序化构建：

- **地板**：大平地色块（约 40×24 世界单位，比准备房大一倍），确保够跑位测远程/冲锋
- **围墙**：四边实体碰撞墙（复用准备房 `BuildRoom` 模式）
- **无装饰**：不放障碍/木桶/地皮/装饰——纯净环境，方便观察怪物行为
- **相机边界**：锁定到围墙范围
- **光照**：默认（不加暗角）

### 2.2 玩家初始化

场景启动后自动完成（跳过准备房的选择流程）：

1. 找到场景中的 Player（或临时实例化）
2. `RunStateCarrier.SetPlayableCharacter(Werewolf)` 写入选定
3. `PlayerStats.ApplyPlayableCharacter(狼人定义)` 应用属性
4. `CharacterSelectUI.ApplyCharacterRuntime` 应用外形/怒痕/兽化
5. `PlayerWeaponHolder.Equip(基础刺刀)` 装备武器
6. 相机 `SnapToTarget`

玩家可以直接开始战斗，不需要按任何确认键。

如果场景中没有 Player（开发者直接 Play 空场景），`TrainingRoomManager` 从 Prefab 实例化一个。

## 3. 快捷键操作

### 3.1 刷怪键（数字键 1~7）

| 键 | 怪物 | Prefab |
|---|---|---|
| 1 | 近战阻挡者 | Enemy |
| 2 | 后排远程 | Enemy_Ranged |
| 3 | 冲锋 | Enemy_Charger |
| 4 | 游击 | Enemy_Skirmisher |
| 5 | 召唤 | Enemy_Summoner |
| 6 | 精英 | Enemy_Elite |
| 7 | 群聚小怪 ×4 | Enemy_Minion（一次刷 4 只成群） |

**刷怪位置**：房间右半区随机合法点（复用 `SpawnPositionHelper.TryFind`，保证不卡墙不重叠）。

**重复按键**：每按一次追加一只（不替换已有），方便测"同时打 N 只"的 AoE 场景。

### 3.2 Boss 刷怪键（B）

| 键 | 动作 |
|---|---|
| B | 刷格兰 Boss（全套组件） |

Boss 刷出时自动调用 `GrandBossBrain.EnsureOn`，确保总脑/双爪/跃击/奔袭/围猎/美术适配层完整挂载。Boss 刷在房间右端中央（留出距离让玩家准备）。

同时生成 `BossArenaState`（石柱三态系统），在房间四角布置 4 根石柱——可以在训练房测完整的撞柱/倒塌/碎石流程。

### 3.3 功能控制键

| 键 | 动作 | 说明 |
|---|---|---|
| K | 杀光全部 | 清场重测（走 `EnemyHealth.TakeDamage(float.MaxValue)`，不走击杀结算） |
| I | 无敌开关 | `Health.GrantIFrames(long.MaxValue)` 或 `IsInvincible` 置位；再按取消 |
| H | 回满状态 | HP/护甲/怒痕/法力 全部回满 |
| F6 | 面板开关 | 显示/隐藏实时统计面板 |

### 3.4 输入实现方式

使用 `UnityEngine.InputSystem.Keyboard.current` 设备直读（与 Tab 地图/J 叙事同模式），不走 `.inputactions` 文件——训练房的按键不属于正式键位表，不随 T-07 重绑。

## 4. 实时统计面板（F6）

### 4.1 数据项

| 显示项 | 计算方式 |
|---|---|
| 当前 DPS | 最近 3 秒窗口内对敌人造成的总伤害 ÷ 3 |
| 本局总伤害 | 从第一次命中开始累计 |
| 最近击杀用时 | 最近一只敌人从刷出到死亡的实际秒数 |
| 存活怪物 | 当前场上存活敌人数量 + 各自 HP 百分比（列表） |
| 玩家状态 | HP/护甲/怒痕/金币（实时） |

### 4.2 伤害追踪方式

订阅 `EnemyHealth.OnTakeDamage` 事件——训练房内刷出的每只怪在生成时自动注册回调，记录每次实际伤害值和时间戳到环形缓冲区（容量 64，非分配）。

### 4.3 UI 实现

`ScreenSpaceOverlay` Canvas（sortingOrder 150，不挡战斗），石板面板视觉（复用 `PanelSprite.ApplyStonePanel`），纯 TMP 文本刷新（每 0.2 秒节流，非每帧）。文本使用 `TMPFontProvider.Font`（项目规范）。

面板始终默认关闭，按 F6 打开。

## 5. Boss 完整测试支持

### 5.1 为什么训练房能测完整 Boss

Boss 的全部组件（总脑/双爪/跃击/奔袭/围猎/美术）都不依赖"地牢场景"——它们挂在 Enemy_Boss Prefab 上，只需要：

- 一个有边界的空间（训练房围墙 ✓）
- 一个目标玩家（训练房自动初始化的玩家 ✓）
- `GrandBossBrain.EnsureOn` 自举（训练房刷怪时调用 ✓）
- `BossArenaState`（石柱系统，训练房手动创建 ✓）

### 5.2 石柱布置

按 B 刷 Boss 时，自动在房间四角（内缩 4 格）各放一根程序化石柱（白色长方体占位），注册进 `BossArenaState`——奔袭撞柱/倒塌碎石/围猎月痕截断全部可测。

### 5.3 Boss 死亡后

自动清理 `BossArenaState` 上的石柱状态（`ResetAll`），下次按 B 重新完整布置。

## 8. 测试与验收矩阵

| 类别 | 必测内容 |
|---|---|
| 玩家初始化 | Play 后狼人外形/刺刀/怒痕全部就绪，无需手动选择 |
| 刷怪 | 每种怪刷出后 AI 正常（巡逻/追击/攻击/技能） |
| Boss | 全部组件挂载；一阶段双爪/跃击可触发；二阶段奔袭/围猎可触发 |
| 石柱 | 奔袭撞柱裂/塌；围猎月痕被柱截断；碎石减速生效 |
| 功能键 | K 全灭不报错；I 无敌期间受伤为 0；H 回满包含怒痕 |
| 统计面板 | DPS 数值合理（与手动计算一致）；击杀用时准确 |
| 隔离 | 训练房的任何操作不影响正式地牢流程 |
| 零 GC | 刷怪/统计刷新无每帧分配（环形缓冲/缓存引用） |

## 10. 验收结论

完成后，开发者测试怪物数值的流程变为：

> 打开训练房场景 → Play → 按 1 刷一只近战怪 → 开打 → 看 F6 面板 DPS → 按 K 清场 → 按 B 刷 Boss 测两阶段。

全程约 5 秒，无需进入地牢。
