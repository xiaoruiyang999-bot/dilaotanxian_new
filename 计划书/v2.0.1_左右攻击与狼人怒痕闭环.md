# v2.0.1 左右攻击与狼人怒痕闭环

> 实施日期：2026-09-10
> 对应真源：《无名之地_完整游戏开发文档_V2》v2.0.1
> 状态：代码与自动验证完成，等待人工手感数据

## 已完成

- 近战攻击方向固定为左/右。键鼠按鼠标世界坐标相对角色的 X 正负定向，Y 不参与；无有效瞄准输入时沿用最后水平朝向。
- 攻击预览、踏步、Hitbox 与伤害继续消费同一段起手时锁定方向；移除运行时四方向 A/B 开关与过期测试。
- 新增 `WerewolfRage` 作为狼人怒痕唯一运行时真值：范围 0～100、正式 Run 内时间恢复、按敌人实际 HP 伤害额外恢复、满怒事件、整条消耗与重置。
- `DamageResolver` 仅在 `EnemyHealth` 发生实际掉血时发布怒痕伤害事件；死亡目标、场景物件与无效伤害不增加怒痕。单次事件和单帧均有限流。
- 狼人 Q 改为满怒兽化，旧 T 轮询停用；未满 Q 只触发短促 UI 反馈，不阻断移动与普通攻击。
- 兽化默认持续 12 秒，开始时消耗整条怒痕，期间暂停充能；结束、死亡和重生均恢复普通形态并重置状态。
- 怒痕 HUD 改为独立 `ScreenSpaceOverlay` 左下角 UI，不再跟随玩家世界坐标。复用现有五张狼人 UI 资源：
  - 普通充能：large 框 + yellow banner 填充；
  - 满怒待释放：medium 框 + 满条 + 单狼头脉冲；
  - 兽化期间：条显示剩余持续时间，两个狼头才开始张合交替。
- 首轮 MVP 输入/UI 只暴露 Space、F、Q；旧 R 武器技与 C 道具入口暂时停用，代码留作迁移兼容。
- 右下技能栏不再显示技能名称；显示图标色块与按键。冷却大于 1 秒显示向上取整整数，最后 1 秒显示一位小数；狼人 Q 未满时显示压暗的资源不可用态。

## 首轮测试参数（T-02/T-03）

- 怒痕上限：100。
- 被动恢复：2/秒，仅正式 Run 开启。
- 实际伤害转化：0.5 怒痕/伤害。
- 单次伤害事件上限：15；单帧上限：20。
- 兽化持续时间：12 秒；兽化/切换期间暂停怒痕获取。
- Space 闪避沿用现有狼人冲刺参数，本版本不锁定最终距离、无敌帧和冷却。
