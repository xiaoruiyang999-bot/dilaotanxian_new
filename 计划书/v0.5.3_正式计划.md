# v0.5.3 正式计划：房间类型系统（含尺寸分级 / 精英混编 / 商店陈列）

> **合并说明（2026-07-23）**：本文档由《v0.5.3 正式计划》与《v0.5.3.1 修改计划》合并而成，描述 v0.5.3 的**最终交付形态**。原 v0.5.3.1 文档已废止。合并要点：房间尺寸分级（整格扩展）、精英混编 minCount 保底、商店 Row 陈列 + 展台、全部房间在初版基础上等比放大（基准 18×11 → 30×18）。

## 版本信息
- **版本号**：v0.5.3（最终版，含原 v0.5.3.1 迭代）
- **版本名称**：房间类型系统（七种房间类型 + 尺寸分级 + 类型化内容装配）
- **前置版本**：v0.5.2（随机内容生成，人工验收通过）
- **状态**：✅ 代码完成（2026-07-23，自动化验收通过，实施记录见 `v0.5.3操作.md`），待人工 Play 验收
- **依据**：《v0.5 Dungeon 系统开发计划书》五-D 节 + 《美术策略变更说明》+ 用户修改需求（2026-07-23：精英混编 ≥1 精英、Boss/精英房放大、商店一列展台、全部房间 1.5×）
- **目标**：Start / Combat / Elite / Treasure / Shop / Event / Boss 七种类型由 `RoomTypeAssigner` 选址、`RoomTypeConfig` 驱动着色/清房条件/内容装配；Boss/精英房大于普通房；精英房混编且至少 1 精英；商店商品一列展台陈列。
- **范围声明（计划书评审意见 #6）**：商店/事件房**只做占位交互**（walk-over 触发），**不做货币、掉落物、购买结算**；Boss 用「大一号敌人」占位，Boss 专属技能属未来版本。
- **约束**：
  1. 不碰 Player/Enemy/Combat/Weapon/UI 任何现有脚本（唯一资产层改动：FloorTile 解锁 LockColor）；
  2. 交互统一 walk-over，不改输入系统；
  3. 布局生成图结构（邻接生长、BFS、Boss/特殊房选址）**不动**——尺寸变化不得破坏 1000 种子自检已验证的不变量；
  4. 一切生成随机走显式 `System.Random`；祭坛 ± 属运行时事件（不进种子流）；
  5. 美术为程序员美术：Tilemap.SetColor 着色 + 白图染色占位 + prefab 变体。

### 1.2 关键工程事实（实施前必须知道）

| 事实 | 影响 |
|------|------|
| **`FloorTile.asset` 的 `m_Flags: 1` = `TileFlags.LockColor`** | `Tilemap.SetColor` 对锁定瓦片**不生效**——必须先改 `m_Flags` 为 0。视觉零变化（Tilemap 默认格色为白）。本版本唯一既有资产改动 |
| 布局随机流在 `TryGrow` 内走完 | 类型分配与尺寸扩展用**独立随机流**（`seed*31+7`），布局流零接触，v0.5.0~v0.5.2 同 seed 复现性零回归 |
| `Enemy.prefab` 中 `attackData` 被 **5 个组件**引用（EnemyCombat/EnemyAI/WeaponController/AttackQuery/WeaponHitbox） | 变体必须全覆盖，漏一处行为不一致 |
| `WeaponController` 编辑器期按 attackData.attackRange 同步武器视觉长度/位置（`scale.y=length`、`pos.x=length/2`） | 变体换 AttackData 后武器视觉自动匹配，出现的 Transform 覆盖是**预期行为** |
| 交互物是 trigger，`SpawnPositionHelper` 的 OverlapCircle（useTriggers=false）看不见 | 随机散点的交互物需自行维护间距并**冲突重试**；Row 陈列在房中心横轴，天然避开 |
| 纯权重表无法保证「至少 1 精英」 | `SpawnTable.Entry` 加 `minCount` 保底语义；**权重 0 的条目不被抽中但 minCount 仍生效**（Boss 严格 1 个靠这条） |
| Play 模式中改 SO 停止后回滚；REST 批量设置含私有字段会整批静默失败 | 资产改动在非 Play 状态做；私有字段逐项 serialized_property + 读回 YAML 核验 |
| Door 门洞地板由 `OpenDoorTile` 重铺 | 门洞格保持默认米黄（不着色），视觉「门槛」，接受为占位表现 |

### 1.3 随机流设计

```
主 seed（DungeonManager.ActiveSeed）
  ├─► 布局流：new System.Random(seed)                    （v0.5.0 起，不动）
  ├─► 类型/尺寸流：new System.Random(seed*31 + 7)         （v0.5.3：Assign → Expand 依次消耗）
  └─► 房间内容流：new System.Random(seed*7919 + roomId)   （v0.5.2 起，不动）

祭坛 ± 50/50：触发瞬间 UnityEngine.Random.value（运行时事件，不进种子流）
```

## 二、目标架构

```
DungeonGenerator.Generate(config, seed)
  → TryGrow（布局生长 + BFS + Boss 选址，不动）
  → RoomTypeAssigner.Assign(layout, config, typeRng)      （纯 C#：特殊房选址 + Elite 抽取）
  → RoomSizeExpander.Expand(layout, config, typeRng)      （纯 C#：Boss 2×2 / Elite 2×1 整格扩展）

DungeonBuilder.Build(layout, config, seed)
  → PaintRoom：按 TileRect(span×粗格) 画房 + RoomTypeConfig.floorTint 地板着色
  → CarveDoor：按含墙矩形判向，门洞在两房内部重叠段居中
  → CreateRoomObject：Bounds=InteriorRect，清房条件数据驱动
  → SpawnContent：按 node.type 取 Profile
       EnemySpawner（minCount 保底混编 + 权重 + 洗牌）
       ObstacleSpawner / DecorationSpawner（不变）
       InteractableSpawner（Random 散点 / Row 一列陈列）

运行时：玩家 walk-over 触发 Interactable → 一次性效果 → 球压暗、展台保留
```

### 2.2 尺寸方案决策（评审记录）

变尺寸打破「全楼层统一尺寸、相邻房共享墙」假设，三方案对比：

| 方案 | 做法 | 结论 |
|------|------|------|
| **A. 整格扩展（选定）** | 房间以 1 粗格为单位；Boss=2×2 格、Elite=2×1/1×2 格，类型分配后吞并空闲格扩展 | 图结构/连接/距离不变、零走廊；失败回退 1×1（尽力满足） |
| B. 精确比例 + 居中 + 走廊 | 节距按最大房预留 | 不可行：普通房之间出现 ~20 格走廊 |
| C. 生成期变尺寸打包 | 生成器重写 | 违背「图结构不动」约束 |

尺寸演进：初版 18×11（v0.5.0 定）→ 20×12（首轮放大）→ **30×18（最终，用户确认「整体再放大 1.5×」）**；Elite/Boss 按比例自动跟随（粗格 32×20：Elite 62×18 或 30×38、Boss 62×38）。

### 3.1 `Assets/Scripts/v0_5/Generation/RoomTypeAssigner.cs`

```csharp
using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// 房间类型分配器（纯 C#，计划书五-D）：Generator 产出布局后运行，只改 RoomNode.type，不动布局。
/// Start=原点、Boss=最远（均由 Generator 定死，本类不碰）；
/// Treasure/Shop/Event 按 DungeonConfig 数量优先叶子房（叶子不够取 distance≥2，再不够任意余房——尽力满足）；
/// 其余 Combat，其中 distance≥2 的按 eliteChance 逐个抽 Elite。
/// 随机流：与尺寸扩展共用独立流（seed*31+7，由 Generator 传入），布局流零接触。
/// </summary>
public static class RoomTypeAssigner
{
    public static void Assign(DungeonLayout layout, DungeonConfig config, System.Random rng)
    {
        // 可分配池：排除 Start 与 Boss（生成器默认全部 Combat，特殊房从中挑走）
        var pool = new List<RoomNode>();
        foreach (RoomNode r in layout.rooms)
            if (r != layout.startRoom && r != layout.bossRoom) pool.Add(r);

        // 固定顺序保证确定性：Treasure → Shop → Event
        AssignSpecial(pool, RoomType.Treasure, config.treasureCount, rng);
        AssignSpecial(pool, RoomType.Shop, config.shopCount, rng);
        AssignSpecial(pool, RoomType.Event, config.eventCount, rng);

        // 剩余 Combat：distance≥2 按 eliteChance 抽 Elite
        foreach (RoomNode r in pool)
        {
            if (r.type != RoomType.Combat) continue;   // 已被特殊房占用
            if (r.distanceFromStart >= 2 && rng.NextDouble() < config.eliteChance)
                r.type = RoomType.Elite;
        }
    }

    /// <summary>从池中挑 count 个房间填为指定类型：叶子优先 → distance≥2 兜底 → 任意余房极端兜底。</summary>
    private static void AssignSpecial(List<RoomNode> pool, RoomType type, int count, System.Random rng)
    {
        for (int i = 0; i < count; i++)
        {
            RoomNode picked = PickRandom(pool, rng, requireLeaf: true, minDistance: 0);
            if (picked == null) picked = PickRandom(pool, rng, requireLeaf: false, minDistance: 2);
            if (picked == null) picked = PickRandom(pool, rng, requireLeaf: false, minDistance: 0);
            if (picked == null) return;   // 池空：尽力满足，数量不足由 Validate 断言按 min(配置, 容量) 核对
            picked.type = type;
            pool.Remove(picked);
        }
    }

    private static RoomNode PickRandom(List<RoomNode> pool, System.Random rng, bool requireLeaf, int minDistance)
    {
        var candidates = new List<RoomNode>();
        foreach (RoomNode r in pool)
        {
            if (requireLeaf && !r.IsLeaf) continue;
            if (r.distanceFromStart < minDistance) continue;
            candidates.Add(r);
        }
        if (candidates.Count == 0) return null;
        return candidates[rng.Next(candidates.Count)];
    }
}
```

### 3.2 `Assets/Scripts/v0_5/Generation/RoomSizeExpander.cs`

```csharp
using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// 房间尺寸扩展器（纯 C#）：类型分配完成后运行，
/// 按类型把大房间「整格扩展」为多格矩形——Boss 优先 2×2，Elite 2×1 或 1×2。
/// 只改 RoomNode 的 span 与 gridPos（锚点=最小角），不碰连接图：
/// 扩展只吞并空闲格，图边两端房间扩展后仍矩形相邻（构造保证）。
/// 失败回退 1×1（尽力满足，与 bossMinDistance 同策略），达成率由 Validate 统计。
/// 随机流：与类型分配共用独立流（seed*31+7），布局流零接触。
/// </summary>
public static class RoomSizeExpander
{
    public static void Expand(DungeonLayout layout, DungeonConfig config, System.Random rng)
    {
        var occupied = new Dictionary<Vector2Int, RoomNode>();
        foreach (RoomNode r in layout.rooms) occupied[r.gridPos] = r;

        // Boss 优先（大图优先保证）：N×N → 2×1/1×2 → 保持 1×1
        if (layout.bossRoom != null && config.bossCellSpan >= 2)
        {
            if (!TryExpandSquare(layout.bossRoom, config.bossCellSpan, occupied, rng))
                TryExpandRect(layout.bossRoom, occupied, rng);
        }

        // Elite：向任一方向扩展 1 格（2×1 或 1×2），失败保持 1×1
        foreach (RoomNode r in layout.rooms)
        {
            if (r.type != RoomType.Elite || config.eliteCellSpan < 2) continue;
            TryExpandRect(r, occupied, rng);
        }
    }

    /// <summary>以房间格为 N×N 方块的任意一角（rng 打乱顺序），四角全部空闲则吞并。</summary>
    private static bool TryExpandSquare(RoomNode room, int n,
        Dictionary<Vector2Int, RoomNode> occupied, System.Random rng)
    {
        var corners = new List<Vector2Int>
        {
            Vector2Int.zero, new Vector2Int(-(n - 1), 0),
            new Vector2Int(0, -(n - 1)), new Vector2Int(-(n - 1), -(n - 1))
        };
        Shuffle(corners, rng);
        foreach (Vector2Int off in corners)
        {
            Vector2Int anchor = room.gridPos + off;
            if (!AreaFree(anchor, n, n, room, occupied)) continue;
            Apply(room, anchor, n, n, occupied);
            return true;
        }
        return false;
    }

    /// <summary>向 E/N/W/S 任一方向（rng 打乱顺序）扩展 1 格，目标格空闲则吞并。</summary>
    private static bool TryExpandRect(RoomNode room,
        Dictionary<Vector2Int, RoomNode> occupied, System.Random rng)
    {
        var dirs = new List<Vector2Int> { Vector2Int.right, Vector2Int.up, Vector2Int.left, Vector2Int.down };
        Shuffle(dirs, rng);
        foreach (Vector2Int d in dirs)
        {
            Vector2Int other = room.gridPos + d;
            if (occupied.ContainsKey(other)) continue;
            var anchor = new Vector2Int(Mathf.Min(room.gridPos.x, other.x), Mathf.Min(room.gridPos.y, other.y));
            Apply(room, anchor, d.x != 0 ? 2 : 1, d.y != 0 ? 2 : 1, occupied);
            return true;
        }
        return false;
    }

    private static bool AreaFree(Vector2Int anchor, int sx, int sy, RoomNode self,
        Dictionary<Vector2Int, RoomNode> occupied)
    {
        for (int x = 0; x < sx; x++)
            for (int y = 0; y < sy; y++)
                if (occupied.TryGetValue(anchor + new Vector2Int(x, y), out RoomNode occ) && occ != self)
                    return false;
        return true;
    }

    private static void Apply(RoomNode room, Vector2Int anchor, int sx, int sy,
        Dictionary<Vector2Int, RoomNode> occupied)
    {
        room.gridPos = anchor;
        room.spanX = sx;
        room.spanY = sy;
        for (int x = 0; x < sx; x++)
            for (int y = 0; y < sy; y++)
                occupied[anchor + new Vector2Int(x, y)] = room;
    }

    private static void Shuffle(List<Vector2Int> list, System.Random rng)
    {
        for (int i = list.Count - 1; i > 0; i--)
        {
            int j = rng.Next(i + 1);
            (list[i], list[j]) = (list[j], list[i]);
        }
    }
}
```

```csharp
// Interactable.cs —— walk-over 基类：Trigger 检测 Player → 一次性 ApplyEffect → 压暗已消耗态
using UnityEngine;

[RequireComponent(typeof(Collider2D))]
public abstract class Interactable : MonoBehaviour
{
    [SerializeField] protected SpriteRenderer visual;
    [Tooltip("已消耗态亮度倍率（压暗表示已用掉）")]
    [SerializeField, Range(0f, 1f)] private float consumedBrightness = 0.35f;

    private bool consumed;

    protected virtual void Awake()
    {
        if (visual == null) visual = GetComponent<SpriteRenderer>();
    }

    private void OnTriggerEnter2D(Collider2D other)
    {
        if (consumed || !other.CompareTag("Player")) return;
        consumed = true;
        ApplyEffect(other);
        SetConsumedVisual();
    }

    /// <summary>一次性效果（治疗/回甲/祭坛±等），由子类实现。</summary>
    protected abstract void ApplyEffect(Collider2D player);

    private void SetConsumedVisual()
    {
        if (visual == null) return;
        Color c = visual.color;
        visual.color = new Color(c.r * consumedBrightness, c.g * consumedBrightness,
                                 c.b * consumedBrightness, c.a);
    }
}

// ChestInteractable.cs —— 宝箱：+2 HP（调现有 Health.Heal），奖励真货挂点即 ApplyEffect
public class ChestInteractable : Interactable
{
    [SerializeField] private float healAmount = 2f;
    protected override void ApplyEffect(Collider2D player)
    {
        if (player.TryGetComponent(out Health hp)) hp.Heal(healAmount);
        Debug.Log($"[Dungeon] 宝箱开启：HP +{healAmount}（占位奖励）");
    }
}

// ShrineInteractable.cs —— 祭坛：±（+2 HP / -1 伤，护甲优先吸收）；运行时随机不进种子流
public class ShrineInteractable : Interactable
{
    [SerializeField] private float healAmount = 2f;
    [SerializeField] private float damageAmount = 1f;
    protected override void ApplyEffect(Collider2D player)
    {
        bool bless = UnityEngine.Random.value < 0.5f;
        if (bless)
        {
            if (player.TryGetComponent(out Health hp)) hp.Heal(healAmount);
            Debug.Log($"[Dungeon] 祭坛祝福：HP +{healAmount}");
        }
        else
        {
            if (player.TryGetComponent(out Health hp)) hp.TakeDamage(damageAmount);
            Debug.Log($"[Dungeon] 祭坛反噬：受到伤害 {damageAmount}（护甲优先吸收）");
        }
    }
}

// SupplyInteractable.cs —— 商店补给：Heal → Health.Heal；Armor → PlayerStats.ModifyArmor
public enum SupplyType { Heal, Armor }

public class SupplyInteractable : Interactable
{
    [SerializeField] private SupplyType supplyType = SupplyType.Heal;
    [SerializeField] private float amount = 2f;
    protected override void ApplyEffect(Collider2D player)
    {
        switch (supplyType)
        {
            case SupplyType.Heal:
                if (player.TryGetComponent(out Health hp)) hp.Heal(amount);
                Debug.Log($"[Dungeon] 拾取治疗球：HP +{amount}（免费占位）");
                break;
            case SupplyType.Armor:
                if (player.TryGetComponent(out PlayerStats ps)) ps.ModifyArmor(amount);
                Debug.Log($"[Dungeon] 拾取护甲球：护甲 +{amount}（免费占位）");
                break;
        }
    }
}
```

### 3.5 `Assets/Scripts/v0_5/Content/InteractableSpawner.cs`

```csharp
using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// 交互物生成器（静态）：宝箱/祭坛/补给，实例化到 contentRoot 下。
/// Random 散点与三 Spawner 同构（trigger 不被 OverlapCircle 看见，
/// 自行维护已放置列表保持 ≥2 格，间距冲突整体重试）；
/// Row 布局按条目顺序在房中心横轴一列排放（商店陈列）。
/// 交互物一律不 RegisterEnemy——与清房条件无关。
/// </summary>
public static class InteractableSpawner
{
    private const float MinSeparation = 2f;

    public static void Spawn(Room room, SpawnTable table, System.Random rng)
    {
        if (room == null || table == null) return;

        // Row 布局：条目即商品，房中心一列排放（商店陈列），不走随机散点
        if (table.layoutMode == SpawnLayout.Row)
        {
            SpawnRow(room, table);
            return;
        }

        int count = table.RollCount(rng);
        var placed = new List<Vector3>();
        for (int i = 0; i < count; i++)
        {
            SpawnTable.Entry e = table.PickEntry(rng);
            if (e == null) continue;

            // trigger 不参与 OverlapCircle，间距靠自行维护的已放置列表；
            // 间距冲突时整体重试（与 TryFind 的 20 次重试同语义，避免冲突直接丢件）
            const int maxAttempts = 10;
            for (int attempt = 0; attempt < maxAttempts; attempt++)
            {
                if (!SpawnPositionHelper.TryFind(room, rng, out Vector3 pos)) break;
                if (TooClose(placed, pos)) continue;

                placed.Add(pos);
                GameObject go = Object.Instantiate(e.prefab, pos, Quaternion.identity, room.ContentRoot);
                go.name = $"{e.prefab.name}_{room.Id}_{i}";
                break;
            }
        }
    }

    private static bool TooClose(List<Vector3> placed, Vector3 pos)
    {
        foreach (Vector3 p in placed)
            if (Vector2.Distance(p, pos) < MinSeparation) return true;
        return false;
    }

    /// <summary>Row 布局：有效条目按列表顺序在房中心横轴一列排放，间距 rowSpacing。
    /// 位置在房中心，天然满足距门 ≥2.5，无需重试。</summary>
    private static void SpawnRow(Room room, SpawnTable table)
    {
        var items = new List<SpawnTable.Entry>();
        foreach (SpawnTable.Entry e in table.entries)
            if (e != null && e.prefab != null) items.Add(e);

        for (int i = 0; i < items.Count; i++)
        {
            float x = room.Center.x + (i - (items.Count - 1) * 0.5f) * table.rowSpacing;
            var pos = new Vector3(x, room.Center.y, 0f);
            GameObject go = Object.Instantiate(items[i].prefab, pos, Quaternion.identity, room.ContentRoot);
            go.name = $"{items[i].prefab.name}_{room.Id}_{i}";
        }
    }
}
```

### 4.4 `Content/EnemySpawner.cs`（两段式保底混编）

```csharp
public static void Spawn(Room room, SpawnTable table, System.Random rng)
{
    if (room == null || table == null) return;

    // 保底：minCount>0 的条目无视权重先行（如精英房至少 1 精英）
    var picks = new List<SpawnTable.Entry>();
    foreach (SpawnTable.Entry e in table.entries)
        if (e != null && e.prefab != null)
            for (int k = 0; k < e.minCount; k++) picks.Add(e);

    int count = Mathf.Max(table.RollCount(rng), picks.Count);
    while (picks.Count < count)
    {
        SpawnTable.Entry e = table.PickEntry(rng);   // 权重 0 的条目永不被抽中（Boss 严格 1 个靠此）
        if (e == null) break;
        picks.Add(e);
    }

    // 洗牌（房间子 seed），避免保底条目固定占据生成顺序前部
    for (int i = picks.Count - 1; i > 0; i--)
    {
        int j = rng.Next(i + 1);
        (picks[i], picks[j]) = (picks[j], picks[i]);
    }

    for (int i = 0; i < picks.Count; i++)
    {
        if (!SpawnPositionHelper.TryFind(room, rng, out Vector3 pos)) continue;
        GameObject go = Object.Instantiate(picks[i].prefab, pos, Quaternion.identity, room.ContentRoot);
        go.name = $"{picks[i].prefab.name}_{room.Id}_{i}";
        room.RegisterEnemy(go.GetComponent<EnemyHealth>());
    }
}
```
