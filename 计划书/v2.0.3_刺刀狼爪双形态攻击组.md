# v2.0.3 刺刀/狼爪双形态攻击组(AttackDefinition 同源消费)

> 对应《无名之地_完整游戏开发文档_V2》§6.2/§7/§22(v2.0.3);分支 feature/battle-logic-loop。

## 已完成

- **`AttackDefinitionAdapter`(新,纯静态数据桥)**:AttackDefinition(SO 绝对值)→
  MeleeComboStep(运行层倍率)一一映射(倍率=绝对值÷AttackData 基准,基准由调用方传入);
  连段窗口取段 0 配置、非法回退 MeleeComboTable 默认。
- **`PlayableCharacterDefinition` + `beastAttack` 字段**:兽化普攻组(狼爪)独立配置。
- **`PlayerCombat.RebuildComboSet()`**:普攻组由职业角色定义驱动(与武器无关,V2 §6.1)——
  装备武器/回默认近战/形态切换统一走此入口;SO 未配置回退 MeleeComboTable 旧链(迁移期兼容)。
- **形态切换接事件**:`WerewolfTransformation.OnBeastFormChanged(bool)`(Enter/Exit 各发一次);
  PlayerCombat 订阅(Awake/OnDisable 配对)——兽化整体换狼爪组、退出回刺刀组;
  切换不打断进行中的攻击段(段参数快照继续有效),仅复位段序/缓冲。
- **资产**:原 Attack_WerewolfClaws 更名+参数化为 **刺刀组**(Attack_WerewolfBayonet:
  突刺直排——reach 2.0/窄带 0.8/踏步 2.6);新建 **狼爪组**(Attack_WerewolfBeastClaws:
  高速短距宽带——前摇 0.08/reach 1.35/带 1.15,不是刺刀×倍率);Character_Werewolf 双组接线。
