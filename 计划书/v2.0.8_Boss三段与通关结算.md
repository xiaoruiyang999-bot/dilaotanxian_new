# v2.0.8 Boss 三段与通关结算(MVP 收口)

> 对应《无名之地_完整游戏开发文档_V2》§9.4(Boss 格兰三段)/§14(通关结算)/§21.1(MVP 验收);
> 分支 feature/battle-logic-loop。

## 已完成

### Boss 三段化(V2 §9.4 守门→追猎→失控)
- `BossPhaseController` 升级:P1 守门(0~50%)现行为 → P2 追猎(≤50%:换池/冷却×0.7/染红脉冲,
  既有)→ **P3 失控(≤25%,新增)**:可选再换池(phase3Attacks 空=沿用)、冷却再×0.85、
  **持续赤红**(失控态视觉)。阈值/倍率/颜色全参数化;低血直跳不漏段(P3 判定前置并涵盖 P2 强化)。
  具体招式差异在 AttackData SO 层配置(代码机制就位,数值调参留数据侧)。

### 通关结算闭环(V2 §14)
- **`RunManager.CompleteRun()`**:随身星蓝币 100% 封存 → VictoryPanel(胜利/楼层/击杀/时长/封存数,
  石板面板)→ Esc/点击返回守灯厅;
- **`PortalInteractable` 改语义**:Boss 清房后的传送门=**通关结算入口**(不再 NextFloor 进下一层)
  ——MVP 单层=Boss 即通关(§21.1 一局 10~15 分钟口径);NextFloor 多层链保留(未来多区域/调试);
- NextFloor 里的过层封结移交 CompleteRun(单次结算,不重复)。
