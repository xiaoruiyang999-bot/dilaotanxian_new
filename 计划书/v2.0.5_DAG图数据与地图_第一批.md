## 已完成(第一批)

### 数据层(纯 C#,V2 §10.1)
- **`DungeonGraphData` / `DungeonGraphNode`**:NodeId/Type/Column/Row/Next/Prev +
  Generated/Discovered/Visited/Completed 状态位(不依赖 GameObject,跨房间卸载持久;
  Active 属于房间运行实例,不入图)。`Validate()` 结构复核:唯一起点/Boss 汇点、
  边只指向更大列(构造即无环)、全可达、Next/Prev 双向一致。`RevealInitial()` 落地
  §10.5 已定案揭示规则(完整连接可见、部分类型未知:起点+直接后继先揭示)。

### 生成器(V2 §10.2/§10.4/§10.6)
- **`DungeonGraphGenerator`**:列式 DAG——5~7 列、每列 1~2 节点、分叉(双出边)与汇聚
  (入边保底)并存;类型按 §10.4 权重(战斗45/事件15/宝箱10/商店10/恢复10/精英10),
  特殊类型最小列距 2(不足降级战斗);Boss 结构固定最末列;seed 复现;验证失败内部
  重试,极端情况纯直线保底(永远合法的 DAG 退化特例)。

### 地图 UI(V2 §16.2,只读预览版)
- **`DungeonMapUI`**:石板面板列式节点图——列自左向右、行错位排布;连线按图数据绘制
  (已推进段金色/其余灰);节点四态:当前(金环)/已完成(暗灰)/已揭示(类型色+汉字图标
  战/精/宝/店/?/愈/王/起)/未揭示(灰暗+?)。Tab 开关。
- 接线:`DungeonManager` 生成层时同步生成图(独立派生流,布局流零接触);
  `PlayerController.Update` Tab 轮询(Input System `Keyboard.current` 设备直读——
  action 表暂无 Map 键,正式 action 化随 T-07 重绑一并做;旧 UnityEngine.Input 红线不适用新 API)。

### 测试(+5,全量 124)
结构合法性 200 seed(无环/单向/唯一起汇/可达/双向一致/Boss 最末列/Start 列 0)、
分叉与汇聚存在性(60 图)、同 seed 确定性、特殊类型列距、揭示规则。
