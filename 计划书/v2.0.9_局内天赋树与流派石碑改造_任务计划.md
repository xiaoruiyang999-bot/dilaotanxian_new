## 1. 本次确定的产品方案

### 1.1 两种界面、一个局内天赋真值

| 场景 | 载体 | 玩家行为 | 是否改变本局战力 |
|---|---|---|---|
| 守灯厅 | 流派石碑 | 查看职业天赋树、选择本局起始铭文 | 是，只授予一个一阶天赋 |
| 地牢房间结算 | 铭文奖励三选一 | 从三个合法天赋中选择一个 | 是，加入当前 Run |
| 暂停页 | 本局构筑页 | 查看已获得节点、下一节点与完整效果 | 否，只读 |
| 局外存档 | 内容解锁 | 记录哪些职业、流派和天赋已进入奖励池 | 不提供永久攻击、生命或暴击数值 |

唯一战力真值是当前 Run 已获得的天赋 ID 集合。石碑、奖励三选一与暂停页都只读写这份集合，不各自保存一套状态。

### 1.2 石碑的新职责

现有 SkillTreeBeacon 改造为“流派石碑”，继续放在守灯厅传送门附近，保留 E 交互与石碑视觉。

石碑打开后执行以下流程：

1. 读取当前选择的职业角色。
2. 展示该职业已开放的流派分支。
3. 展示每条分支的四个小天赋、成型终局效果、关键代价和反制。
4. 玩家选择一个“一阶起始铭文”作为本局起点。
5. 起始铭文写入 Run 天赋状态，并让对应分支获得前两次奖励的倾向权重。
6. 玩家仍可在局内转入其他分支，不进行流派锁死。
7. 切换职业角色时清除尚未进入地牢的起始铭文，要求重新选择。
8. 进入地牢后石碑选择锁定；死亡或通关返回守灯厅后开启下一局选择。

石碑不再消耗魂晶，不再提供永久攻击、移速、攻速、生命、护甲或暴击伤害。

### 1.3 为什么不把整棵树做成局外永久树

- V2 的核心是每局形成不同 Build，永久点满会让选择失去机会成本。
- 旧技能树只有固定百分比，不表达怒痕、破甲、流血和贴脸循环。
- 新石碑仍保留“进本前查看和选择”的仪式感，但只决定当局起点。
- 局外成长继续以解锁职业、流派、遗物、事件和敌人为主。

## 2. 首发狼人天赋树

### 2.1 树形结构

狼人核心能力“刺刀攻击、怒痕 0～100、Q 兽化、狼爪、流血、破甲”不是可选节点，而是职业底座。

职业底座向外展开四条线，每条四个节点：

| 分支 | 第一阶：起手 | 第二阶：循环 | 第三阶：转化 | 第四阶：成型 |
|---|---|---|---|---|
| 怒痕兽化爆发 | 破笼兽化 | 狼爪连斩 | 破甲撕咬 | 余怒回潮 |
| 破甲处决 | 穿刺刻痕 | 钉牢伤口 | 贯穿窗口 | 破城处决 |
| 流血猎杀 | 开放伤口 | 加深感染 | 蔓延血迹 | 血潮 |
| 贴脸追击 | 猎杀半径 | 贴身压迫 | 撕开防线 | 危险距离 |

所有效果和数值直接引用十九流派数值表，不在本任务文档复制第二份可编辑数值。

### 2.2 节点解锁规则

- 第一阶无前置，可由守灯厅石碑选为起始铭文，也可在局内开启新分支。
- 第二至第四阶必须已拥有同分支上一阶。
- 一次奖励只能选择一个节点。
- 同一节点每局只获得一次，不做重复升级。
- 已成型分支仍可与其他分支组合，但后续奖励降低该成型分支的出现权重。
- 一局允许多分支混搭，不要求先点满一条才能点另一条。
- 第四阶不是额外第五个“终极天赋”；四个节点同时拥有时自然形成数值表中的完整效果。

### 2.3 起始铭文规则

- 玩家必须在进入地牢前选择一个起始铭文；未选择时传送门提示“先在流派石碑铭刻本局起点”。
- 首发狼人可选：破笼兽化、穿刺刻痕、开放伤口、猎杀半径。
- 起始铭文免费，不消耗星蓝币。
- 同一次 Run 内不可更换。
- 石碑选择只提高前两次奖励中同分支后继节点的出现概率，不保证整局只能玩该流派。
- 推荐首测权重：前两次主要天赋奖励各保证至少一个同分支合法后继；第三次起恢复普通标签加权。

## 3. 局内天赋奖励规则

### 3.1 奖励职责拆分

现有 NodeRewardService 将金币、治疗、攻击强化、武器与遗物混在同一组选择中。改造后按职责分开：

| 奖励类型 | 推荐来源 | 是否占用天赋选择 |
|---|---|---|
| 天赋铭文 | 主要战斗房、精英房 | 是，固定三选一 |
| 星蓝币 | 清房掉落、宝箱、事件 | 否 |
| 治疗 | 药剂、恢复节点、商店 | 否 |
| 武器变体 | 武器架、精英或商店 | 否 |
| 遗物 | 精英、Boss、商店 | 否 |
| 纯攻击 +12% / +25% | 从主要奖励池移除 | 不再作为占位奖励 |

目的：玩家完成战斗后能稳定推进 Build，不会因为被迫在治疗和天赋之间选择而长期无法成型。经济与恢复的机会成本放在路线和商店中承担。

### 3.2 三选一组成

每次生成三个不重复选项：

1. 关联位：当前起始分支或已投入最多分支的合法后继节点。
2. 联动位：与已有状态、攻击标签或资源存在联动的节点。
3. 开拓位：其他未开启分支的一阶节点，或适配当前职业的通用天赋。

保底规则：

- 前两次主要奖励至少出现一个起始分支后继节点。
- 连续两次未出现任何已有分支后继时，第三次强制提供。
- 不展示前置未满足的二至四阶节点。
- 不展示已经获得的节点。
- 候选不足三个时，才使用武器、遗物或恢复作为补位；不得用永久攻击百分比补位。
- 所有随机由 Run seed、房间 ID 和奖励序号共同决定，退出重进不能刷新结果。

### 3.3 奖励节奏

首轮建议：

- 开局石碑：1 个一阶天赋。
- 普通主要战斗房：每房 1 次天赋三选一。
- 精英房：1 次高关联天赋三选一，并单独结算遗物。
- Boss 房：战斗前不再发新天赋；Boss 后进入通关奖励与结算。
- 单局目标获得 5～8 个局内天赋，通常完成一条四节点主流派，并拥有 1～4 个副流派节点。

若当前 8～12 房全部触发奖励导致成长过快，再在实测后改为每 2 个普通战斗房触发一次；首轮任务不同时改房间节奏与天赋数值。

## 4. 19 流派与职业天赋树的投放关系

十九流派是完整战斗库，不等于每个职业都拥有相同的十九棵树。

| 批次 | 职业/来源 | 使用流派 |
|---|---|---|
| P0 首发 | 狼人 | F01 怒痕爆发、F03 破甲、F09 流血、F14 贴脸 |
| P1 狼人扩展 | 狼人/通用遗物 | F02 普攻、F04 暴击、F07 闪避、F08 续航、F13 虚弱、F16 反击、F17 自残、F18 蓄力 |
| P2 法师 | 法师/法术遗物 | F05 护甲、F06 反伤、F08 续航、F10 引爆、F11 腐化、F12 冻结、F13 虚弱、F17 自残、F18 蓄力、F19 契约 |
| P2 弓箭手 | 弓箭手/远程遗物 | F02 普攻、F03 穿透、F04 暴击、F07 闪避、F13 虚弱、F15 风筝、F16 反击、F18 蓄力、F19 契约 |

同一流派跨职业时可以共享设计骨架，但必须使用该职业已有资源和攻击标签。例如狼人恢复怒痕、法师恢复法力、弓箭手缩短蓄力或闪避冷却，不建立共用“主资源”。

P0 数据表只录入狼人 16 个节点。其余 60 个节点保留在设计文档中，不提前制作空资产或运行状态。

## 5. 界面与交互任务

### 5.1 守灯厅流派石碑

目标布局：

- 顶部：当前职业角色、职业资源说明和“本局起始铭文”状态。
- 中央：四条横向分支，每条四个节点；已开放、可选起点、未获得后继使用不同视觉。
- 右侧详情：流派完整效果、当前节点效果、代价、推荐联动。
- 底部操作：选择起始铭文、确认、返回。
- 尚未制作的职业或流派只显示剪影，不显示伪造数值。

石碑世界表现：

- 保留当前碑体、交互范围与 E 交互。
- 三色旧符文改为四个狼人分支符号；首轮允许继续使用程序化色块占位。
- 已选起始铭文后，对应符文常亮；未选时四个符文缓慢轮流呼吸。
- 石碑只在守灯厅可交互，地牢内不生成同名对象。

### 5.2 局内奖励三选一

每张铭文卡必须展示：

- 天赋名称。
- 所属流派与阶位。
- 精确数值效果。
- 前置节点已满足提示。
- 与当前 Build 的关系：后继、联动或新分支。
- 代价文字；不得只写收益。

选中后：

- 立即写入 Run 天赋状态并生效。
- 播放对应分支色反馈。
- 关闭选择界面。
- 保存当前节点完成状态与本次奖励结果。

### 5.3 暂停页“本局构筑”

- 替代旧暂停菜单中的永久技能树入口。
- 只读展示当前职业四条分支。
- 已获得节点点亮，下一合法节点描边，其余压暗。
- 顶部显示本局主流派判定：已投入节点最多的分支。
- 分支四节点齐全时显示“已成型”和完整终局效果。
- 提供当前流血、破甲、怒痕等词条说明，不允许在暂停页加点或重随。

## 6. 数据与运行职责计划

以下是实施时的职责边界，不要求在计划阶段创建文件。

| 模块 | 职责 | 建议形态 |
|---|---|---|
| TalentDefinition | ID、职业、流派、阶位、前置、标签、名称、描述、数值配置 | ScriptableObject |
| TalentCatalog | 按职业与解锁状态提供静态定义 | 只读目录 |
| RunTalentState | 已选起始铭文、已获得 ID、奖励序号、倾向分支 | 纯 C# 数据，归 RunStateCarrier/ActiveRun |
| TalentOfferService | 根据 seed、前置、标签与保底生成三个候选 | 纯 C#，可测试 |
| TalentRuntime | 接收“获得/清空/重建”事件并协调效果模块 | 薄门面 |
| 狼人天赋效果模块 | 怒痕、破甲、流血、贴脸四组运行逻辑 | 小型独立模块 |
| BuildTreeUI | 守灯厅可选、暂停页只读两种模式 | 表现层 |
| RewardChoiceUI | 展示候选并回调选择 | 不保存数值、不直接修改 PlayerStats |

约束：

- 静态数值只存在 TalentDefinition，不把数值复制进 UI。
- RunTalentState 不依赖场景 GameObject 是否激活。
- DamageContext 只结算单次攻击，不保存连击或流派层数。
- EnemyStatus 继续保存流血与破甲；不为 P0 新增法师腐化、冻结或契约状态。
- 高频命中不使用 LINQ、字符串查询或临时集合。
- 天赋订阅必须在死亡、通关、重开和职业切换时成对清理。

## 7. 开发任务拆分

- [ ] 明确旧魂晶存档不转换为星蓝币。

### T2 石碑改造

- [ ] 将 SkillTreeBeacon 的入口切换到新流派石碑界面。

### T3 奖励池与保底

- [ ] NodeRewardService 增加天赋候选数据，但不在服务中应用效果。
- [ ] TalentOfferService 实现前置过滤、去重、标签权重与保底。
- [ ] RewardChoiceUI 支持天赋卡字段。
- [ ] RoomRewardHook 只负责请求候选和把选择交回运行层。
- [ ] 将纯攻击强化移出主要 Build 奖励池。
- [ ] 将金币、治疗、武器和遗物迁到各自掉落或房间奖励出口。
- [ ] 奖励结果接入 ActiveRun 保存，禁止强退刷新。

退出条件：固定 seed 重复进入相同房间得到相同候选；前两次奖励都含起始分支合法后继。

### T4 狼人四分支效果

按依赖顺序制作：

1. 破甲处决：复用现有破甲，优先验证伤害管线与目标条件。
2. 流血猎杀：复用现有 5 层流血，验证刷新、转移和真伤。
3. 贴脸追击：建立统一距离判定，供四个节点共用。
4. 怒痕兽化爆发：接入 0～100 怒痕、Q 兽化和狼爪攻击标签。

每完成一条分支：

- [ ] 四个节点可分别单独生效。
- [ ] 四节点齐全时与数值表完整效果一致。
- [ ] 代价同样生效，不能只实现收益。
- [ ] 死亡、通关、重开后状态归零。
- [ ] 多段命中、Boss 阶段、目标死亡等边界有测试。

退出条件：四条 Build 均可在受控奖励序列中稳定成型。

### T5 本局构筑 UI 与反馈

- [ ] 暂停页新增只读本局构筑树。
- [ ] HUD 只显示当前真正需要操作的计数器。
- [ ] 天赋获得、分支成型与终局触发具备区分反馈。
- [ ] 补齐流血、破甲、怒痕、贴身距离的说明文本。
- [ ] 键鼠与手柄均可选择、确认、返回。

退出条件：玩家不查看外部文档也能说明当前主流派、下一节点和核心代价。

### T6 旧永久技能树安全退役

- [ ] 新链通过验证后停止 SkillTreeDef 与 SkillTreeSave 的运行引用。
- [ ] PlayerStats 不再聚合旧永久百分比。
- [ ] DeathPanel 不再按击杀发放魂晶。
- [ ] 暂停菜单不再打开旧 SkillTreeUI。
- [ ] 保留旧存档键但停止读取，不直接删除玩家本地数据。
- [ ] 确认无 Prefab、场景、测试或文档继续引用旧类后再删除代码。
- [ ] 同步 README、V2 主文档和开发必读中的退役状态。

退出条件：新石碑与局内天赋链完全可用，旧树零运行引用，且没有缺失脚本。

### T7 平衡与完整 Run 验收

- [ ] 使用四套固定奖励序列分别测试四条纯流派。
- [ ] 使用两套混搭序列测试跨分支组合。
- [ ] 记录普通房清理时间、精英时间、Boss 时间、承伤与触发次数。
- [ ] 检查 5～8 次选择能否形成一主一副。
- [ ] 检查起始分支保底是否过强。
- [ ] 只在完整 Run 数据后调整十九流派数值表。

退出条件：至少三条狼人 Build 能在 20～30 分钟目标 Run 中被玩家明确识别，且不存在唯一最优起始铭文。

## 8. 测试与验收矩阵

| 类别 | 必测内容 |
|---|---|
| 前置 | 未拥有上一阶时绝不出现二至四阶 |
| 去重 | 已拥有节点不再进入候选 |
| 保底 | 前两次奖励至少一个起始分支后继 |
| 确定性 | 同 seed、房间、奖励序号得到相同候选 |
| 生命周期 | 新 Run 初始化；死亡、通关清空；断点恢复 |
| 职业隔离 | 狼人池不出现法师、弓箭手节点 |
| 效果组合 | 单节点、两节点、四节点和跨分支组合 |
| 伤害标签 | 直伤、DOT、真伤、狼爪、刺刀、重击不串线 |
