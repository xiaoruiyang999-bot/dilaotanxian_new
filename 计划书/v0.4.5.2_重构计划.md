# v0.4.5.2 开发计划——攻击动画系统重构（Attack Animation Framework）

> 版本：v0.4.5.2
>
> 类型：系统重构（Framework Refactor）
>
> 目标：统一玩家、敌人攻击动画框架，实现动画与攻击判定同步，并为 v0.5 技能系统预留完整扩展能力。

---

# 一、开发目标

本次版本**不新增任何玩法**，仅重构当前攻击动画框架。

目前攻击系统已经能够运行，但架构存在以下问题：

- WeaponAnimator 同时负责动画、初始化、缩放、朝向，职责过重。
- Player 与 Enemy 使用同一套动画逻辑，但两者攻击表现完全不同。
- Player 武器初始位置错误，攻击结束后姿态异常。
- Player 武器不能始终跟随鼠标朝向。
- Enemy 武器无法真正围绕角色完成 360° 旋转。
- AttackData 同时承担攻击参数与动画算法职责。
- WeaponPivot 与 WeaponSprite 初始化逻辑混入攻击流程。

本次重构目标：

- 攻击配置数据驱动（AttackData）
- 动画播放独立驱动（WeaponAnimator）
- Player / Enemy 状态机只负责攻击流程
- Combat 只负责命中判定与伤害
- 动画表现与攻击判定保持一致
- 为 Boss、技能、武器系统预留扩展接口

最终形成如下架构：

```
AttackData
        │
        ▼
WeaponAnimator
        │
        ▼
PlayerCombat / EnemyAI
        │
        ▼
EnemyCombat / PlayerCombat
```

各层职责完全解耦。

# 三、AttackData 重构

AttackData 作为**唯一攻击配置数据**。

职责：

- 保存攻击参数
- 保存动画参数
- 不保存任何运行状态
- 不包含任何运行逻辑

---

## 保留字段

```
WindupTime

ActiveDuration

RecoveryTime

AttackRange

AttackAngle

AttackDamage

AttackCooldown

TargetLayer

AttackEase

ActiveMomentRatio
```

---

## 删除字段

删除：

```
StartAngle

EndAngle
```

原因：

StartAngle、EndAngle 属于动画算法。

不是配置。

以后不同动画计算方式不同。

不能放在 AttackData 中。

---

## 新增攻击动画类型

新增：

```csharp
public enum AttackAnimationType
{
    Arc,
    FullCircle,
    Thrust,
    Spin,
    Throw
}
```

AttackData 增加：

```csharp
[SerializeField]
private AttackAnimationType animationType;

public AttackAnimationType AnimationType => animationType;
```

---

## 当前版本使用

Player：

```
AnimationType = Arc
```

Enemy：

```
AnimationType = FullCircle
```

Boss：

```
Spin
```

枪：

```
Thrust
```

飞刀：

```
Throw
```

虽然目前只实现 Arc 与 FullCircle，但必须预留其余接口。

# 四、WeaponAnimator 重构

WeaponAnimator 为**纯动画播放器**。

禁止知道：

```
Player

Enemy

Boss

Combat

Target

Distance

Damage

Cooldown

State
```

WeaponAnimator 唯一职责：

> 播放武器动画。

---

## 初始化

Awake()

执行：

```
ApplyWeaponScale()

初始化 WeaponSprite Rotation

初始化 WeaponSprite Position
```

要求：

初始化只执行一次。

禁止：

每次攻击重新计算。

---

## 新增接口

```csharp
public void SetAimDirection(Vector2 direction)
```

职责：

更新武器平时朝向。

逻辑：

```
如果正在播放动画

return
```

否则：

```
weaponPivot.right = direction;
```

---

## PlayAttack()

根据：

```
AttackAnimationType
```

播放不同动画。

---

### Arc

用于：

```
Player

普通近战

剑

斧

镰刀
```

动画：

```
-AttackAngle/2

↓

+AttackAngle/2
```

禁止：

```
FastBeyond360
```

---

### FullCircle

用于：

```
Enemy

Boss

旋风斩
```

动画：

```
当前方向

↓

当前方向 +360°
```

必须：

```
RotateMode.FastBeyond360
```

Enemy：

永远完整旋转一圈。

不要读取：

```
AttackAngle
```

---

### Thrust

暂不实现。

仅保留接口。

---

### Spin

暂不实现。

仅保留接口。

---

### Throw

暂不实现。

仅保留接口。

---

## Stop()

职责：

停止 Tween。

恢复：

```
weaponPivot.localRotation

=

Quaternion.identity
```

不要恢复：

```
WeaponSprite
```

---

## ApplyWeaponScale()

职责：

根据：

```
AttackRange
```

自动调整：

```
WeaponSprite 长度

WeaponSprite 宽度

WeaponSprite 位置
```

仅：

```
Awake()
```

执行一次。

# 五、PlayerCombat 重构

PlayerCombat 负责：

- 玩家攻击流程
- 玩家鼠标朝向
- 调用 WeaponAnimator

不负责动画算法。

---

## 新增

```
UpdateAiming()
```

每帧：

获取：

```
Mouse Position
```

计算：

```
Direction
```

调用：

```
weaponAnimator.SetAimDirection(direction)
```

---

## 攻击期间

若：

```
weaponAnimator.IsPlaying == true
```

则：

禁止继续更新方向。

保持攻击开始时方向。

攻击结束后：

恢复跟随鼠标。

---

## 玩家攻击动画

Arc。

例如：

AttackAngle = 90°

实际动画：

```
-45°

↓

45°
```

攻击判定：

保持与动画一致。

---

# 六、EnemyAI 重构

Enemy：

没有鼠标。

每帧：

```
FaceTowards(Player)
```

然后：

```
weaponAnimator.SetAimDirection(playerDirection)
```

攻击期间：

WeaponAnimator 自动忽略方向更新。

Enemy：

永远朝向玩家。

攻击时：

围绕当前朝向完整旋转：

```
360°
```
