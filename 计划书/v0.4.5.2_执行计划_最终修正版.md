# v0.4.5.2 执行计划（最终修正版）

> 版本：v0.4.5.2
>
> 目标：将 `WeaponAnimator` 彻底降维为纯动画执行器，所有攻击方向、角度、范围、视觉长度等计算全部上移到 `PlayerCombat` / `EnemyAI`，为 v0.5 技能、武器、Boss、多段攻击预留最清晰的扩展接口。

---

## 一、为什么需要再次修正

### 原最终版计划仍存在的问题

原最终版计划虽然移除了 `WeaponAnimator` 对 `AttackData` 的直接引用，但 `WeaponAnimator` 仍然承担以下业务：

| 原 WeaponAnimator 职责 | 问题 |
|---|---|
| `SetAimDirection()` | 管理武器平时朝向，属于业务层 |
| `aimAngle` / `playStartAimAngle` | 维护瞄准状态，属于业务层 |
| Arc / FullCircle 角度计算 | 知道攻击类型与角度，属于业务层 |
| `Stop()` 恢复 `playStartAimAngle` | 管理攻击结束后的朝向，属于业务层 |
| `RefreshWeapon()` | 管理武器视觉长度，属于显示层 |

这些问题导致：

- `WeaponAnimator` 仍不是真正可复用的动画播放器。
- 未来技能系统（如蓄力、多段、组合技）无法灵活组合动画。
- Boss 攻击如果角度特殊，仍需修改 `WeaponAnimator`。
- 武器长度、视觉表现与动画播放耦合。

### 新方案如何解决

- `WeaponAnimator` 只接收：开始旋转、结束旋转、持续时间、Ease、RotateMode、触发比例、回调。
- `WeaponAnimator` 输出：Tween 动画。
- 所有方向、角度、范围、恢复逻辑由 `PlayerCombat` / `EnemyAI` 计算并传入。
- 武器 Sprite 长度由 `PlayerCombat` / `EnemyAI` 直接控制（v0.5 再抽取为 `WeaponView`）。

## 二、最终职责划分

| 模块 | 负责 | 不负责 |
|---|---|---|
| **AttackData** | 攻击参数配置：Range、Angle、Type、Damage、Cooldown、TargetLayer、Windup、Active、Recovery、Ease、MomentRatio | 动画计算、运行逻辑 |
| **PlayerCombat** | 玩家攻击状态机、鼠标方向计算、Arc 起止角度计算、伤害判定、武器 Sprite 长度设置 | Tween 播放 |
| **EnemyAI** | 敌人攻击状态机、玩家方向计算、FullCircle 起止角度计算、调用 EnemyCombat、武器 Sprite 长度设置 | Tween 播放 |
| **WeaponAnimator** | 播放动画：接收起止旋转、执行 Tween、触发命中回调 | 攻击逻辑、方向、角度、范围、Sprite 缩放 |
| **EnemyCombat** | 冷却、范围判定、伤害 | 动画 |
| **WeaponView（v0.5）** | 武器显示：长度、宽度、位置、Sprite 旋转 | 攻击判断 |

## 三、WeaponAnimator 最终 API

```csharp
using UnityEngine;
using DG.Tweening;
using System;

/// <summary>
/// 纯动画执行器。
/// 只负责按调用方给定的起止旋转播放 Tween。
/// 不读取 AttackData，不计算角度，不管理瞄准，不管理 Sprite 缩放。
/// </summary>
public class WeaponAnimator : MonoBehaviour
{
    [SerializeField] private Transform weaponPivot;

    private Tween rotationTween;
    private Tween momentTween;

    public bool IsPlaying => rotationTween != null
        && rotationTween.IsActive()
        && rotationTween.IsPlaying();

    /// <summary>
    /// 播放一次旋转动画。
    /// </summary>
    /// <param name="startEuler">开始欧拉角（世界空间）</param>
    /// <param name="endEuler">结束欧拉角（世界空间）</param>
    /// <param name="duration">动画持续时间</param>
    /// <param name="ease">动画曲线</param>
    /// <param name="rotateMode">DOTween 旋转模式</param>
    /// <param name="activeMomentRatio">命中触发比例</param>
    /// <param name="onActiveMoment">命中回调</param>
    public void Play(
        Vector3 startEuler,
        Vector3 endEuler,
        float duration,
        Ease ease,
        RotateMode rotateMode,
        float activeMomentRatio,
        Action onActiveMoment = null)
    {
        Stop();

        if (weaponPivot == null || duration <= 0f)
        {
            onActiveMoment?.Invoke();
            return;
        }

        weaponPivot.rotation = Quaternion.Euler(startEuler);

        if (onActiveMoment != null)
        {
            float momentDelay = duration * Mathf.Clamp01(activeMomentRatio);
            momentTween = DOVirtual.DelayedCall(momentDelay, () =>
            {
                onActiveMoment?.Invoke();
                momentTween = null;
            });
        }

        rotationTween = weaponPivot
            .DORotate(endEuler, duration, rotateMode)
            .SetEase(ease)
            .OnComplete(() => rotationTween = null);
    }

    /// <summary>
    /// 停止 Tween。不修改 WeaponPivot 任何 Transform。
    /// </summary>
    public void Stop()
    {
        rotationTween?.Kill(complete: false);
        momentTween?.Kill(complete: false);
        rotationTween = null;
        momentTween = null;
    }
}
```

**说明：**

- 使用 `Vector3` 欧拉角而非 `Quaternion`，是因为 `FullCircle` 需要表达 `θ` 与 `θ + 360°` 的差异，`Quaternion` 无法区分。
- `RotateMode` 由调用方传入：`Arc` 用 `RotateMode.Fast`，`FullCircle` 用 `RotateMode.FastBeyond360`。
- `Stop()` 仅停止 Tween，不恢复任何旋转。

## 四、PlayerCombat 角度计算

### Arc 动画

```csharp
// 获取鼠标方向
Vector2 mousePos = Camera.main.ScreenToWorldPoint(Mouse.current.position.ReadValue());
Vector2 dir = (mousePos - (Vector2)transform.position).normalized;
float theta = Mathf.Atan2(dir.y, dir.x) * Mathf.Rad2Deg;

// 计算起止角度
float half = attackData.AttackAngle * 0.5f;
Vector3 startEuler = new Vector3(0, 0, theta - half);
Vector3 endEuler = new Vector3(0, 0, theta + half);

// 播放
weaponAnimator.Play(
    startEuler,
    endEuler,
    attackData.ActiveDuration,
    attackData.AttackEase,
    RotateMode.Fast,
    attackData.ActiveMomentRatio,
    OnActiveMoment
);
```

### 待机朝向管理

- 未攻击时，每帧计算鼠标方向，直接设置 `weaponPivot.rotation = Quaternion.Euler(0, 0, theta)`。
- 攻击期间（`weaponAnimator.IsPlaying`），不更新朝向。
- Recovery 结束后，恢复为当前鼠标方向。

### 武器 Sprite 长度

- 在 `StartWindup()` 中：
  ```csharp
  weaponSprite.localScale = new Vector3(weaponWidth, attackData.AttackRange, 1f);
  weaponSprite.localPosition = new Vector3(attackData.AttackRange * 0.5f, 0f, 0f);
  ```

## 七、为什么新方案不会导致旧问题

### 为什么 Player 攻击结束不会跳角度？

- `WeaponAnimator.Stop()` 不恢复 identity。
- `PlayerCombat.UpdateRecovery()` 结束时，手动将 `weaponPivot.rotation` 设置为当前鼠标方向。
- 恢复逻辑在 Combat 层，可由调用方决定是否平滑过渡（v0.5 可加插值）。

### 为什么 Enemy 能完整 360° 旋转？

- `EnemyAI` 计算 `startEuler = (0,0,θ)`，`endEuler = (0,0,θ+360)`。
- 传入 `RotateMode.FastBeyond360`。
- `WeaponAnimator` 仅执行 Tween，不干预角度。

### 为什么 Arc 围绕瞄准方向？

- `PlayerCombat` 计算 `startEuler = (0,0,θ-AttackAngle/2)`，`endEuler = (0,0,θ+AttackAngle/2)`。
- `θ` 取自攻击瞬间的鼠标方向。
- 动画中心精确锁定当前瞄准方向。

### 为什么 Tween 和 Update 不会抢 Rotation？

- `WeaponAnimator` 内部没有 `Update()`。
- `PlayerCombat` / `EnemyAI` 在 `!weaponAnimator.IsPlaying` 时才更新朝向。
- Active / Recovery 期间，只有 Tween 修改 `weaponPivot.rotation`。

## 八、v0.5 / v0.6 / v0.7 扩展方案

### v0.5 技能系统

- 新增 `SkillData` 或复用 `AttackData`。
- `PlayerCombat` 扩展为支持技能队列、连击、蓄力。
- 每个技能计算自己的起止旋转，调用同一个 `WeaponAnimator.Play(...)`。
- `WeaponAnimator` 无需任何修改。

### v0.6 Boss 系统

- Boss 的 AI 脚本（如 `BossAI`）计算特殊起止角度：
  - 扇形扫射：`θ - 110°` → `θ + 110°`
  - 全屏旋风：`θ` → `θ + 720°`
- 调用 `WeaponAnimator.Play(...)` 即可。
- 无需修改 `WeaponAnimator`。

### v0.7 武器系统

- 武器长度、Sprite、特效由独立 `WeaponView` 组件管理。
- `PlayerCombat` / `EnemyAI` 在换武器时通知 `WeaponView` 更新。
- `WeaponAnimator` 仍只负责动画。
