# 《无名之地》v2.1.0 小版本计划书：规则冻结与唯一 Run 数据基座

> 编写日期：2026-09-17
> 实施基线：`main` / `a09031a`（已合并 `battle-logical`）
> 上位依据：《无名之地_完整游戏开发文档_V2.md》与《v2.1_三流派肉鸽核心与单向DAG总计划.md》
> 本版本目标：把 v2.1 的稳定规则变为可序列化、可迁移、可测试的数据合同；保留当前可玩入口。
> 执行状态：代码与文档已落盘；Unity Test Runner 的 EditMode 实跑已于 2026-09-18 完成（190/190 通过）。

## 1. 范围与冻结口径

1. `PlayableCharacterId` 仍是唯一职业角色身份。每局解铭阶位从 1 开始、最高 5；只影响揭印品阶，不影响角色基础属性。升阶逐级购买，使用随身星蓝币。
2. 首批刻印固定 13 个稳定 `AbilityId`：裂星 5、疾刃 4、血誓 4。每个 ID 固定谱系与 I～III 品阶；同名再次获得只升级该 ID，建议上限 3 级，不增加“不同刻印”数量。IV～VI 只保留数据扩展位，不投放空卡。
3. 五级六档概率只维护总计划 §3.4 的一张矩阵。1 级 I/II 为已定案的 60/40；其他行和升阶价作为可调的首轮测试基线。实际候选过滤空池后仅对正权重品阶归一化，0% 不复活。
4. 谱系共鸣只按同谱系不同 `AbilityId` 数量计算，2/4 张分别解锁两档，4 张叠加 2 张效果。本版本只计算状态，不接入战斗效果。
5. 图节点的数据状态拆分为 `Generated / Discovered / Selected / Visited / ObjectiveCompleted / RewardResolved / Completed`。目标完成不等于领奖；领奖前不能标记节点最终完成。节点 Seed 与状态不依赖 GameObject。
6. 奖励和商店事务使用稳定 `RunId + NodeId + Source + Sequence` 标识。交易记录在 ActiveRun 内保存；升阶只允许在当前已进入的商店节点，重复调用不得重复扣款或增加解铭阶位。

展示名、2～5 级概率、升阶价和刻印数值沿用总计划的首轮测试基线，仍可在后续平衡阶段调整；稳定 ID、序列化字段含义和已定案的规则不随展示名调整。

## 2. 数据合同与兼容迁移

| 数据 | v2.1.0 落点 | 本版本门禁 |
|---|---|---|
| DAG | `DungeonGraphData` / `DungeonGraphNode` | 增加 v2.1 节点类型、四类节点 Seed、房间原型 ID 和领奖状态；保留旧枚举整数值 |
| 本局存档 | `SaveService.ActiveRunData` | 保存 RunId、完整图、当前节点、生命/护甲/法力/职业资源、星蓝币、刻印、背包、待选奖励、商店和事务记录 |
| 刻印 | `SageInscriptionCatalog` / `RunBuildState` | 13 个稳定 ID、固定谱系/品阶、按不同 ID 统计共鸣、同名升级不越级 |
| 解铭 | `InscriptionRankRules` | 唯一五级六档矩阵、逐级价格、合法品阶过滤与归一化 |
| 交易 | `RunTransactionRules` | 稳定事务 ID、重复升阶幂等、余额不足和跳级拒绝 |

`ActiveRun` Schema 从 v1 升到 v2。迁移保留旧 HP、护甲、货币、职业、遗物、击杀和楼层；新增字段补默认值。v1 不含真实 DAG，不能从旧房间对象推断玩家所在节点，因此迁移后的档标记为待路线初始化，留给 v2.1.1 在明确入口下接管。旧 `RunManager` 在本版本不读取新字段。

Profile 只升级版本号，不改变原数据含义。读档升级后写回新 Schema，并保留旧文件备份；高版本档仍按现有策略备份并拒绝降级读取。

## 3. 实施顺序

1. 扩展节点和 ActiveRun 的纯数据字段，保持既有枚举、类名和旧入口兼容。
2. 建立 13 刻印目录、Build 持有状态、解铭矩阵与纯数据交易规则；不挂场景对象、不启用新 UI。
3. 完成 v1→v2 存档迁移、默认值修复和往返序列化。
4. 增加 EditMode 测试：旧档迁移、图状态与 Seed 往返、13 ID 唯一性、同名升级与 2/4 共鸣、六档矩阵及 0% 过滤、升阶幂等。
5. 编译并运行可用的自动检查；记录实际改动和未接入的后续环节。

## 4. 验收与版本边界

- 新建与 v1 升级的 ActiveRun 均可序列化往返，旧字段不丢失；旧档没有假造的当前 DAG 节点。
- 所有 13 个 ID 唯一且品阶固定；重复获取最多升到 3 级，共鸣只计不同 ID。
- 五行概率各合计 100；未实装品阶与 0% 品阶无法抽到；合法池为空有明确失败结果。
- 升阶只允许 1→2→3→4→5，价格按目标等级读取；重复事务不再次扣款。
- 当前地牢与 Boss 流程仍由原入口运行。节点驱动房间、三选一、商店 UI、背包/Buff 实际效果和战斗共鸣分别在 v2.1.1～v2.1.7 实施。
