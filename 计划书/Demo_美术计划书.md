## 一、美术方向（已定稿，2026-07-29）

1. **视角/画风**：游戏逻辑俯视（无跳跃无重力），Sprite 用**平面/正视画风**绘制（元气骑士式：俯视逻辑 + 正视观感角色图）。对代码零影响，只换贴图。
2. **风格**：传统地下城风。
3. **角色**：**原创 + 非人形**（圆滚动物系方向，"圆圆的大狗"那类）；禁用现成梗形象（大狗叫/哈吉米/赛马娘/叮咚鸡，版权红线）。
4. **生产方式（2026-07-29 定稿）**：位图 + 无骨骼。流程 = **AI 生成视频 → 工具导出序列帧 → 程序脚本批处理（抽帧/抠图/对齐）→ 接入 Unity**。美术 C 负责出设定图与生成视频，序列帧后处理全部由程序脚本完成（批处理脚本写一次复用，不逐张耗 AI token）。
5. **武器仍走挂载**：角色序列帧**空手、不画武器**（手部姿态保持固定），武器沿用 WeaponPivot 独立挂载 + DOTween 动效，与现有架构完全一致。
6. **流程**：占位色块先行 → 剪影/设定稿评审 → AI 视频 → 序列帧导出 → 脚本批处理 → 程序接入（换 Sprite 零代码改动）。

## 二、规格

| 项 | 规格 |
|----|------|
| 画布 | 角色/敌人 56×56 或 64×64【定稿后回填】；Boss 可按 2 倍体型的 96×96 或 128×128 |
| 格式 | 透明底 PNG，Point 过滤，边缘清晰 |
| 命名 | `角色名_状态_帧号.png`（`Warrior_Move_1.png`）；部件 `角色名_Part_部件名.png` |
| 调色 | 沿用《美术策略变更说明.md》配色语义：战士红系、小怪土橙、精英紫黑+金边、Boss 深红+暗黑；正式图在该体系内细化 |
| 识别规则 | 远看剪影分档：普通=单色圆滚无部件、精英=+部件+金边+1.3×、Boss=多部件+核心+2×；主角与怪物剪影绝对区分 |
| 序列帧规范 | ①每状态 2~6 帧（从视频抽帧降频，勿全量导出；小怪 Move 4~5 帧，各角色实际帧数以用户提供的素材帧数为准）；②全部帧**统一画布尺寸、以脚底中心为 pivot 对齐**（程序脚本批量对齐）；③视频用**纯色/绿幕背景**生成，脚本批量抠图出 alpha；④角色帧**空手不画武器**；⑤**方向拆分：玩家移动/待机做正/侧/背三方向（侧向程序镜像出左右），攻击只做正面+侧面（背面用侧面镜像兜底）；敌人圆滚非人形不分方向，单套即可** |
| 帧动画播放 | 程序侧写通用帧切换器（FrameAnimator，按状态+方向播序列帧、帧率可调），不引骨骼动画插件 |
| 武器挂点 | **逐帧挂点表**：每套攻击序列帧配一份 JSON（每帧 = 握点像素坐标 + 武器角度）；AI 读图在关键帧标定、中间帧程序插值生成，附 Editor gizmo 工具供人工微调；运行时 FrameAnimator 逐帧驱动 WeaponPivot 到挂点；镜像时挂点 x 与角度自动取反 |

## 三、敌人设计约束（给形象设定用）

- 小怪 A 近战：需要"要挥击"的姿态帧；
- 小怪 B 远程：需要明显的"发射口/法器"部件 + 蓄力姿态；
- 小怪 C 冲撞：需要低头/尖角的冲撞姿态；
- 精英 A/B：复用小怪底稿 + 换色 + 1~2 个部件（角/金环），**不要重画**；
- Boss：P1/P2 两形态（可同底稿换色+部件差异），3~4 个招式姿态【具体招式待用户设计稿】。

## 六、接入约定（程序侧执行）

1. 占位替换 = 换 SpriteRenderer.sprite + 关染色，代码零改动；
2. 帧动画用程序侧通用帧切换器（FrameAnimator）播序列帧，武器动效保留 DOTween；精英换色走程序染色，不需重画；
3. 渲染层级不变：玩家 10 / 武器 11 最高；
4. 每件接入后截图存档 `Assets/Screenshots/`，并回填《美术策略变更说明.md》执行记录。
