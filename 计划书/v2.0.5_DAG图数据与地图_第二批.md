## 已完成

### 运行架构:全链直建 → 单 Active 房间(V2 §11.3 MVP)
- **`DungeonManager`**:LinearHorizontal 拓扑下 `Generate` 改为图驱动单房——生成 DAG 后
  只建**当前节点**的房间(`BuildSingleNode`:单节点 mini layout 走完整 Builder 房间管线,
  塑形/内容/轮次/Boss 仪式厅旁路逻辑照旧);LegacyGrid 保持全图直建(回退口)。
  新增 `Graph`/`CurrentNodeId` 运行真值与 `TransitionToNode(nodeId)`:
  黑屏淡入(0.25s)→ 清场重建 → 玩家摆房间**左侧入口**(V2 左入右出)→ 相机 Snap → 淡出(0.35s)。
- 节点类型映射:NodeType→RoomType(Recovery→Event 占位);图状态维护:进入标记 Visited/
  Generated,后继标记 Discovered(揭示规则 §10.5)。

### 节点推进器:`DungeonNodeRunner`(新组件,DungeonManager 挂载)
- 完成判定分型(V2 §11.1):**战斗/精英/Boss = Room.OnRoomCleared**;
  **非战斗(宝箱/商店/事件/恢复)= 玩家抵达房间右侧出口区**(x ≥ Bounds.xMax−2.5);
  Start 房=空房直接走右侧出口。
- 完成 → 节点 Completed → 0.6s 后弹**交互式 DAG 选择**;选完 → TransitionToNode → 订阅新房。
- **Boss 节点不弹选择**:清房奖励(宝箱+传送门)与下一层入口由既有 RunManager.OnBossCleared
  链负责,玩家主动点传送门进下一层——两条链零冲突。

### 地图 UI 交互化:`DungeonMapUI.OpenInteractive(graph, currentId, onPick)`
- 当前节点的直接后继=**可选**:金色描边+Button 可点,点击关闭界面回调选择;
  其余节点只读;Esc 关闭(不选,可重新走到出口再弹?当前实现:关了可再触发——右侧检测
  已 reachedExit 一次性……弹窗取消后可 Tab 只读查看,推进暂停等待再弹由后续微调)。
  Tab 只读模式保留(预览全图)。

## Play 走查清单

1. 进地牢:只有**一间房**(当前节点),Tab 看图(起点金环);
2. 清房(战斗)或走到右侧出口(商店等)→ 0.6s 弹路线图,**金色节点可点**;
3. 选择 → 黑屏过渡 → 新房从左侧进入;原节点变灰(已完成);
4. 一路选到 Boss:清 Boss → 房内宝箱+传送门 → 点传送门下一层(新 DAG 新起点)。
5. 不可逆:已选路线回不去(每房独立重建,无回头路)。
