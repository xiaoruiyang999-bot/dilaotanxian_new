# v2.1.3 问题汇总与修复记录

> 2026-09-24 建立；实施中持续更新。记录格式：症状、证据、根因、处理、验证、遗留项。

## 1. 新 C# 文件没有进入既有本地工程文件

- 症状：首次 `dotnet build Game.csproj` 报找不到 `InscriptionCombatRuntime`。
- 证据：生成的 `Game.csproj` 仍是新增文件前的显式 Compile 清单。
- 根因：本地 Unity 项目文件尚未由 Editor 刷新；并非源码缺少命名空间。
- 处理：只在 Git 忽略的本地 `Game.csproj`/`EditModeTests.csproj` 加入新增文件，以便独立编译。新脚本的 `.meta` 已随源码落盘；Unity 重新导入时会重建工程文件。
- 验证：`dotnet build EditModeTests.csproj` 0 错误。
- 遗留项：UnitySkills REST 服务未响应，尚未从编辑器确认自动导入与 Test Runner 结果。

## 2. Unity 6 对旧实例 ID API 报编译错

- 症状：`GetInstanceID()` 在当前 Unity 6000.5.4f1 引用下报 CS0619。
- 证据：编译器明确提示使用 `GetEntityId`。
- 根因：当前 Unity API 已禁用旧方法。
- 处理：目标身份键改为 `GetEntityId().GetHashCode()`，仅用于本房间内裂痕与击杀去重，不写入存档。
- 验证：`Game` 与 `EditModeTests` 编译 0 错误。
- 遗留项：无。

## 3. 浮点断言精度

- 症状：临时额外生命 15% 上限的受控断言得到 `15.000001`，严格等值断言失败。
- 证据：独立规则测试首次 5 通过、1 失败；失败值与期望差约 0.000001。
- 根因：32 位浮点乘法舍入。
- 处理：断言改为 0.0001 容差，运行时上限仍由 `Mathf.Min` 限制。
- 验证：受控规则测试 9/9 通过。
- 遗留项：无。

## 4. 验证环境

- 症状：UnitySkills `/health` 在 8090～8100 均无响应，项目同时有 UnityLockfile。
- 证据：端口探测返回 `UNITY_SKILLS_UNAVAILABLE`；本地 Unity 进程与项目锁存在。
- 根因：当前 Editor 未开放本任务可用的 UnitySkills REST 测试面；不能据此推断 Editor 本身编译或运行失败。
- 处理：使用本地 Unity 引用编译 `Game` 与 `EditModeTests`，并在独立受控入口运行纯规则 NUnit 断言。没有另启同项目 Unity 实例，避免与用户正在使用的编辑器争用项目锁。
- 验证：编译 0 错误；规则断言 9/9 通过。
- 遗留项：Unity Test Runner 全量 EditMode、Console 红错与准备房 Play 冒烟仍需在可访问的 Editor 会话中执行。

## 5. 召唤物击杀可刷血誓击杀收益

- 症状：直接按 `EnemyHealth.IsDead` 结算猎获与血誓初鸣，会把召唤师无限生成的小兵计为有收益击杀。
- 证据：既有 `EnemyCombat.SummonMinions` 把召唤物 `EnemyController.DropCoins` 设为 false 以防刷币。
- 根因：刻印运行状态最初只收到“死亡”事实，没有继承已有无收益目标标记。
- 处理：`EnemyHealth.EligibleForKillRewards` 读取现有掉币资格；猎获叠层与击杀回复只在目标有收益时结算。直接有效伤害的基础吸血仍受单次/每秒上限约束。
- 验证：新增无收益召唤物受控断言，整组 9/9 通过。
- 遗留项：后续若出现不掉币但应触发击杀奖励的特殊敌人，应将收益资格拆成独立数据字段。

## 6. 同一敌人的多个碰撞体可能重复推进刻印

- 症状：原 `WeaponHitbox` 仅按 `Collider2D` 去重，原范围技能逐 Collider 结算；同一 `IDamageable` 若拥有多个实体碰撞体，一次攻击可能多次扣血并推进暴击/连击/吸血。
- 证据：原命中集合是 `HashSet<Collider2D>`；`CastMeleeAoE` 遍历 `OverlapCircleAll` 时没有目标身份去重。
- 根因：去重单位是物理形状，不是受伤目标。
- 处理：近战挥击与范围技能均复用 `HashSet<IDamageable>`；贯穿计数改为不同受伤目标的数量。
- 验证：`Game`/`EditModeTests` 编译 0 错误，受控纯规则断言 9/9 通过。
- 遗留项：多碰撞体的实际 Physics2D 命中场景仍待 Unity Test Runner/Play 验证。
