# 《无名之地》v2.1.3 小版本计划书：十三刻印与共鸣战斗框架

> 编写日期：2026-09-24；实施前制定。上位依据：《无名之地_完整游戏开发文档_V2.md》与《v2.1_三流派肉鸽核心与单向DAG总计划.md》。

## 1. 范围

- 以既有 `RunBuildState` 为唯一持有真值，补齐 13 张 I～III 刻印的三级静态数值与战斗效果；同名升级不增加不同刻印数。
- 建立疾刃、裂星、血誓的 2/4 共鸣运行状态，按 Build 重建；新 Run、死亡、房间切换时清理短时和目标相关状态。
- 对普通攻击、投射物和直接技能的有效伤害接入暴击、吸血及条件触发；攻速入口使用同一上限和溢出结算。
- 以受控 EditMode 测试验证数值边界、一次暴击、有效伤害、触发去重、共鸣不递归及存档 Build 重建。

本版不替换 v2.1.2 临时奖励 UI；正式石碑、揭印、物资背包和商店分别由 v2.1.4～v2.1.6 接入。

## 2. 结算合同

1. 静态定义包含固定 `AbilityId`、谱系、品阶、效果类型和每级明确数值；不把首级数值直接乘级数。
2. 基础攻速与所有加成先汇总，生效攻速封顶 2.5 倍；`余势`只读取正向溢出，攻击增益最多 20%，不反馈进攻速。
3. 一次直接命中只掷一次暴击；只有对敌人实际扣血的命中推进蓄隙、连锋、共鸣与吸血。附加打击直接扣血，不再触发暴击、吸血、连击或其他刻印。
4. 吸血按最终有效直接伤害算，不吃过量伤害。单目标每次最多回最大生命 8%，每秒最多 20%；Boss 吸血再乘 0.5。临时额外生命上限为最大生命 15%，到时消失。
5. 低血增益统一按当前生命/最大生命，25% 以下封顶。目标低血判定取命中前生命比例。
6. 共鸣以不同 `AbilityId` 达 2/4 生效；击杀仅计一次。房间切换清理敌人裂痕与击杀标记，短时战斗状态按运行生命周期清理。

## 3. 实施步骤

1. 补静态数值表和纯规则运行状态，建立可重建、可清理的战斗规则 API。
2. 接入玩家直接伤害、攻速与受敌伤害路径；由 `RunManager` 在职业角色应用后绑定当前 ActiveRun Build。
3. 编写有意义的受控结算测试，再编译、运行 EditMode、检查 Unity Console 和 Play 冒烟。
4. 维护同目录问题记录，并在根目录写本版实际实施记录。

## 4. 验收

- 13 张效果和六个共鸣档位的受控测试覆盖边界和去重；Build 升级与共鸣计数保持兼容。
- 无刻印时现有攻击行为不变；有刻印时近战、投射物、直接技能走统一结算。
- 编辑器脚本编译、EditMode 和 Play 冒烟无新增错误；ActiveRun 不访问或清理真实玩家存档来做测试。
