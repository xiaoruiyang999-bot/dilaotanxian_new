# v0.7.1 正式计划：减伤甲体系（玩家+怪物通用）+ 删除呼吸回甲

> 版本线：《v0.7_Demo玩法计划书.md》§九 v0.7.1 执行卡。总纲决策 3：减伤甲双倍率、受伤同时扣甲扣血、护甲归零免伤失效、删呼吸回甲。
> 公式口径：《伤害计算公式文档.md》§三（本文不重复公式，只写接线）。前置：v0.7.0 已完成（六维字段含 armorReduceMul/armorLossMul 占位 R=0.3/L=1.0、DamageResolver 单点收口）。

## 一、目标与范围

1. **玩家减伤甲**：Health 结算改双倍率公式（扣血=伤害×(1−R)、扣甲=伤害×L），护甲归零全额扣血；**删除呼吸回甲**（脱战回复字段+计时+Update 逻辑）；
2. **怪物护甲**（仅精英/Boss）：EnemyStats 加护甲三字段，EnemyHealth 按同一公式结算；
3. **敌人护甲条**：精英/Boss 头顶血条加钢灰护甲条（复用 WorldSpaceHealthBar 双条化）；
4. 公式**玩家/怪物共用一份实现**（DamageResolver 纯函数），禁止两处各写一份。

**明确不做（本版）**：敌人攻击力属性接入伤害管线（v0.7.8）、道具甲包（v0.7.3）、天赋/刻印对 R/L 的修饰（框架已留修饰器口，后续接）、任何美术替换。

## 二、改动清单

### 2.1 共用公式（DamageResolver.cs 扩展，不新建文件）

新增静态纯函数：

```
ApplyArmor(float damage, float armor, float reduceMul, float lossMul, out float armorAfter) → float hpDamage
  armor > 0：hpDamage = damage × (1 − reduceMul)；armorAfter = max(0, armor − damage × lossMul)
  armor ≤ 0：hpDamage = damage（全额）；armorAfter = 0
```

边界规则照公式文档 §六：扣甲溢出不转嫁（本次扣血仍按有甲算完）；R∈[0,0.9]、L>0 由数据侧保证（OnValidate 钳制）。

### 2.2 修改脚本（6）

| 文件 | 改动 |
|------|------|
| `Combat/DamageResolver.cs` | +`ApplyArmor` 纯函数（见 2.1） |
| `Player/PlayerStats.cs` | **删**呼吸回甲：`armorRegenRate`/`armorRegenDelay`/`lastDamageTime`/`isOutOfCombat`/`Update` 内护甲回复块/`OnTakeDamage()` 方法；`AbsorbDamageWithArmor` **改写成** `ApplyArmorDamage(float damage) → float`（调 DamageResolver.ApplyArmor，触发 OnStatsChanged）；`ModifyArmor` 保留（甲包/护甲球用）；R/L 字段钳制 OnValidate（R≤0.9，L>0） |
| `Player/Health.cs` | TakeDamage 内 `stats.AbsorbDamageWithArmor(damage)` → `stats.ApplyArmorDamage(damage)`；删 `stats.OnTakeDamage()` 调用（该方法随回甲删除） |
| `Enemy/EnemyStats.cs` | +`maxArmor`（默认 0=普通怪无甲）/`armorReduceMul`（默认 0）/`armorLossMul`（默认 1）三字段 + 属性外露；OnValidate 钳制；**ApplyFloorScale 只缩 HP，护甲不随楼层缩放**（注释说明，【待补充·数值】若后续要缩再开） |
| `Enemy/EnemyHealth.cs` | +`currentArmor`/`MaxArmor`（Awake 从 EnemyStats 读）+ `OnArmorChanged(current,max)` 事件；TakeDamage 走 DamageResolver.ApplyArmor（无甲敌人 armor=0 天然全额扣血，**普通怪路径数值不变**）；`ResetHealth` 同步回满护甲；+`AddArmor(float)` 预留 |
| `Enemy/WorldSpaceHealthBar.cs` | 双条化：数据源为 EnemyHealth 且 MaxArmor>0 时，HP 条上方加**钢灰护甲条**（#708090，高度为 HP 条约 1/3 的细条，canvasSize 相应加高）；订阅 OnArmorChanged；玩家/无甲敌人零变化 |

### 2.4 顺路确认（不改逻辑）

- `SupplyInteractable` 护甲球 → 走 PlayerStats.ModifyArmor，新体系下语义不变（回甲手段），回归验证即可；
- `ShrineInteractable` 祭坛自伤 → Health.TakeDamage 现走减伤甲公式（有甲时自伤被减免+扣甲），属预期行为变化，验收时确认可接受；
- 旧场景（v0_4/v0_5）敌人无 EnemyStats 护甲字段 → 默认 0，零影响。

## 六、验收清单

> 场景：`v0_7_PrepRoom` → `v0_7_ClassWeapon`；Game 1920×1080；回归 `v0_4_EnemySystem`/`v0_5_Dungeon`。

1. `dotnet build Assembly-CSharp.csproj`：0 警告 0 错误；
2. grep `armorRegen|ArmorRegen|OnTakeDamage`：PlayerStats/Health 零残留（EnemyHealth.OnTakeDamage 事件保留勿动）；
3. **公式四边界**（对照公式文档 §三算例）：
   - 玩家有甲挨 4 伤：扣血 2.8、扣甲 4（R=0.3/L=1.0）；
   - 护甲打到 0 后：全额扣血 4，免伤失效；
   - 一击 15 打穿 10 甲：扣血仍按有甲算（×0.7=10.5），溢出不转嫁；
   - 精英（AR=10/R=0.2/L=1.0）挨 15：扣血 12、扣甲 15→甲 0；
4. **呼吸回甲消失**：脱战站立 10 秒护甲不回；
5. **敌人护甲条**：精英/Boss 头顶出现钢灰细条且随扣甲缩短；普通怪没有；
6. **回归**：木桩场景、商店护甲球回甲、祭坛事件、法力球/宝箱全流程无损。
